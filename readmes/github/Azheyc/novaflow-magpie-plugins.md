# NovaFlow for Magpie

在官方 Magpie 客户端中连接 NovaFlow，使用账户获授权的 AI 模型，并从企业技能商店安装、更新和分享技能。

- **账户同步**：使用专用连接密钥登录，为每个授权 Key 自动配置独立的 Magpie 原生供应商，名称显示来源分组。
- **供应商图标**：添加分组后自动同步 NovaFlow Logo；后续可自行更换，账户同步会保留您的选择。
- **原生模型与请求**：模型列表、思考强度、图片与视频识别和推理请求全部使用 Magpie 原生逻辑，插件不改模型 ID、不解析或转发推理请求。
- **企业技能商店**：按公司分类浏览和搜索技能，查看分享者、说明、版本及文件预览。
- **分享本机技能**：将已加入 Magpie 资料库的技能分享给同事。
- **配置初始化**：可重复执行；初始化状态默认折叠，操作按钮保持可见。
- **主题适配**：插件页面跟随 Magpie 的浅色、深色主题。

需要 Magpie **0.1.2058 或更新版本**及 NovaFlow 账户；建议更新至 **0.1.3375 或更新版本**，以使用完整的页面恢复和技能路由能力。插件固定使用 [NovaFlow 官网](https://www.ycnovaflow.vip)，并兼容官方无 `www` 域名 `https://ycnovaflow.vip`；无需自行配置服务器。

## 安装

在 Magpie 的插件页面添加 GitHub 仓库，或在终端运行：

```sh
magpie plugin add github:Azheyc/novaflow-magpie-plugins
```

也可以从 [Releases](https://github.com/Azheyc/novaflow-magpie-plugins/releases) 下载生产包，解压后在 Magpie 中选择该目录安装。不要直接把 `.tgz` 文件作为插件目录添加。

插件安装后会添加侧栏 **NovaFlow** 入口；也可从供应商或 Agent 的右键菜单进入。登录后按授权 Key 创建分组供应商。请避免同时启用多个 NovaFlow 插件副本。

## 登录

1. 登录 [NovaFlow](https://www.ycnovaflow.vip)，打开「个人资料」。
2. 在「Magpie 插件连接密钥」中生成或复制当前密钥。
3. 在 Magpie 侧栏打开「插件 → NovaFlow」，粘贴密钥并点击「连接 NovaFlow」。
4. 插件自动创建「NovaFlow · 分组名」原生供应商并触发获取模型，在 Magpie 原有的模型、路由和 Agent 页面选择使用。

连接密钥以 `nfpc_` 开头，专用于插件连接，不能使用模型 API Key、账户密码代替。账户只保留一个当前连接密钥；轮换后，需要使用新密钥重新登录。

## 模型连接

账户登录、同步状态和退出统一在插件侧栏页面操作。模型在自动创建的「NovaFlow · 分组名」原生供应商中；同组多个 Key 会进一步显示 Key 名称。

插件只同步供应商地址、Key 和平台协议地址，模型原始名称及模型请求交给 Magpie。重复后台同步不反复写配置或获取模型；点击「立即同步」可重新触发 Magpie 获取模型。员工已选择的模型、供应商开关及其他原生设置会保留。若手动改过插件创建的连接地址或 Key，插件会提示冲突，不覆盖该连接。

退出登录只清除本机登录状态和插件创建且仍由插件管理的连接，不会撤销平台连接密钥，也不影响其他设备继续使用该密钥；手动添加的供应商和已安装技能不会被删除。停用或卸载插件前，请先在插件页面退出登录。

## 图片与视频

NovaFlow 模型目录会标注支持的图片和视频类型，Seedance 系列在获取模型后自动识别为视频模型。手动修改过的模型类型会保留。

更新插件后，已启用的受管分组会补充刷新一次目录；失败可点击「立即同步」重试。停用的供应商保持停用。

## 页面连接

页面连接超过等待时间会显示「重新连接」，不会一直停留在加载画面。切回插件或恢复联网时会重新读取状态。安装、分享等操作超时后，请先刷新确认结果，再决定是否重试，避免重复提交。

本机服务暂时失联时会尝试重新连接官方插件入口，恢复不成功则显示重试指引。若仍无法打开，请关闭并重新进入 NovaFlow 插件页；无需退出账户。仍无法连接时，检查 Magpie 是否正常运行，以及本机安全软件是否拦截回环连接。

## 菜单栏额度

在 Magpie「设置 → 菜单栏显示额度」中选择任一已启用的「NovaFlow · 分组名」。个人账户显示个人可用余额，企业账户显示公司共享可用余额，单位为人民币。各分组查询的是同一账户余额。

原先选择了旧 NovaFlow 账户入口的，插件同步时会迁移到有效分组；未开启过菜单栏额度的，不会自动开启。余额按照 Magpie 设置的间隔刷新，也可在其用量页面手动刷新。手动配置的余额查询保持原样。

## 企业技能

企业账户在插件侧栏中可浏览本公司的技能商店，按分类和安装状态筛选，或搜索技能名称、分享者和关键词。打开技能详情可预览包文件，再选择安装或更新。

- 技能按需安装，插件不会自动安装整个公司目录。
- 安装成功以 Magpie 资料库实际登记及包文件校验为准，安装后可在资料库中关联需要的 Agent。
- 兼容 Magpie 技能路由；更新保留原有 Agent 关联、路由或直连选择，不自动开启技能路由。
- 首次使用会自动初始化 Magpie 资料库，无需手动创建目录。
- 新安装使用技能原标识；同名本机技能会提示冲突，不直接覆盖。
- 公司下架或删除技能后，已安装副本保留，但停止提供下载和更新。

### 分享技能

只有**已加入 Magpie 资料库（资源库）的技能**才能分享。

1. 打开 Magpie「资源库 → 技能」，导入 Agent 中已有的技能，或通过本机文件夹路径查找并添加。
2. 技能文件夹根目录必须包含大小写准确的 `SKILL.md`；ZIP 包请先解压。
3. 回到 NovaFlow 插件，打开「分享技能」并刷新技能列表。
4. 选择技能，预览文件，确认名称与用途说明，选择公司分类后提交。

用途说明默认读取资料库中的技能说明，可以修改；无需填写技能标识。提交成功后，同公司员工即可在商店安装。分享会将预览确认的文件上传到 NovaFlow，请勿在技能包内放置凭据或私密资料。

企业管理员在 NovaFlow 网页「技能与同步」中管理技能分类、上传、上下架、删除和版本。个人账户保留账户同步及配置初始化；企业技能操作显示为不可用，并提供开通企业账号的指引。

## 配置初始化

插件页面的「配置初始化」由用户点击并确认后执行，可以重复使用：

- 安装内置 `magpie-image` MCP，并关联 Magpie 已接管的 Agent。
- 从已获取的生图模型中选择；优先保留当前有效选择，支持 `gpt-image-2`、`gpt-image-2.5`、`gpt-image-2.6` 等已授权模型。
- 将 Magpie 更新渠道设为稳定版。

初始化要求 NovaFlow 账户已登录，且 Magpie 已获取可用生图模型。多个候选且当前未设置时，需要自行选择。登录、后台同步或「立即同步」不会触发初始化。重复初始化会重新应用上述设置；关联 MCP 可能使 Agent 重新读取配置。

## 连接与数据

插件只连接 `https://www.ycnovaflow.vip`，不提供服务器地址输入项。`127.0.0.1:3488` 是桌面插件的本机页面服务，由插件自动管理；新版 Magpie 为非页面 CLI 宿主分配的临时端口也由插件自动适配。

连接密钥和模型 API Key 保存在 Magpie 配置目录内受保护的本机文件中。连接密钥用于账户同步和余额查询，模型 API Key 用于模型调用。连接密钥和模型 API Key 不会显示在插件页面或写入 URL、日志。模型调用、技能目录和分享由 NovaFlow 提供；公司权限以平台当前授权为准。

## 常见问题

**输入密钥后点击「连接 NovaFlow」没有反应？** 请升级到插件 1.6.3 或更新版本。旧版登录按钮使用了 Magpie 沙箱禁止的原生表单提交，点击时不会发出登录请求。新版通过页面命令连接，支持点击和回车；无效密钥会显示错误提示。

**Windows 插件页显示「127.0.0.1 拒绝连接」？** 请升级到插件 1.6.2 或更新版本。旧版页面嵌入策略遗漏 Windows Magpie 的窗口来源，可能被 WebView2 拦截。下载新版生产包，解压后在 Magpie 中更新插件并重启；同一时间只启用一个 NovaFlow 插件副本。若仍报错，在浏览器打开 `http://127.0.0.1:3488/`：能够打开说明本机服务已启动；也无法打开时，请检查 Magpie 插件是否启用及其启动错误日志。这个地址由插件提供，无需安装 NovaFlow 后端。

**没有可用模型？** 在插件页面确认已连接，再查看「NovaFlow · 分组名」原生供应商，确认已启用且连接密钥有效，然后点击同步。企业账户还需由管理员配置模型分组和权限。

**找不到本机技能？** 先在 Magpie 资源库完成导入，再刷新分享列表。仅存在于磁盘、尚未加入资料库的文件夹不会列出。

**安装失败？** 根据插件显示的原因处理后重新安装。下载完成不等于登记成功，请同时查看 Magpie 资料库的登记结果。

**轮换密钥后无法同步？** 在插件页面退出后，使用 NovaFlow 个人资料页中的新连接密钥重新连接。
