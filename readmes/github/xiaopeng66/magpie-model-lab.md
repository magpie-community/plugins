# 模型实验室 · Model Lab

**在 Magpie 中评测 AI 模型能力、比较推理表现，并按计划持续测试。**

模型实验室把鹈鹕 HTML 动画、模型指纹、原糖果推理题和定时自动测试放在同一个页面。直接使用 Magpie 已配置的供应商和模型，可比较回答、查看思考与输出用量、回放动画、追踪每日表现。

**1.0.9** · MIT · Magpie 0.1.2905+ · [GitHub Release](https://github.com/xiaopeng66/magpie-model-lab/releases/tag/v1.0.9)

Model Lab evaluates and compares AI models in Magpie through HTML animations, model fingerprints and the original candy reasoning puzzle, with per-model scheduled tests. It uses your existing providers and keeps results locally.

## 能做什么

| 页面 | 功能 |
| --- | --- |
| **鹈鹕动画** | 同一提示词生成“鹈鹕骑自行车”HTML 动画，多模型并排预览；支持重播、浏览器打开、查看源码，以及在 Windows Edge 中导出 GIF。 |
| **模型指纹** | 每个模型进行 3 次数字采样，与参考库匹配；显示采样进度、候选模型和详细证据。 |
| **糖果测试** | 只保留原糖果题，答案为 **21**；高级设置可重复测试，不设固定轮数上限；各模型／账号的轮次相邻排列，详情显示判分与重复统计。 |
| **自动测试** | 每个模型／账号目标分别设置糖果、动画计划；糖果用成功率与时间格展示，动画按目标排列为横向长廊。 |
| **历史记录** | 手动结果按提交批次查看，自动结果按日期、类型和时刻分组；支持备注检索、组合筛选、记录保护、保留时间及批次 JSON 留档。 |

- **先选供应商，再选模型**：默认显示全部供应商，支持搜索、多选、一键清空和跨供应商对比。列表每 5 分钟自动刷新，也可手动刷新。
- **参数自己控制**：可选择模型支持的思考档位、输出上限、生成超时与并行数；插件不限制单批模型数量。
- **模式记忆与常用参数**：三种手动测试分别保存参数；「常用参数 → 添加 / 编辑方案」直接编辑名称、超时、输出上限、并行数及模式专用参数，保存后可应用到测试。保存未确认时保留草稿，生成采用点击时的参数。
- **多账号独立评测**：同模型可选自动分配或多个固定账号，普通供应商的主 Key 和附加 Key 也可分别勾选，对比不同分组的同名模型；收藏、计划、历史和原条件复测保留目标身份。只有可信路由证据才显示账号已核实。
- **配置导入与分享**：专用 JSON 可去除账号绑定，导入时重新绑定、选择保留或覆盖，预览后确认；受影响或新计划保持暂停。
- **请求控制与每日统计**：按供应商／固定账号设置并行和间隔，保留 429 等待；每日用量展示请求数、已知 Token 和来源明细，指纹每个采样分别记账。删除历史不会减少用量。
- **重复测试**：糖果原题支持重复轮次，接受可精确表示的正整数；结果按模型／账号分行，各轮连续排列，执行按轮次交错。各轮使用同一题面、答案和判分条件，汇总成功率与耗时。准备数据超过 8 MiB 时在保存和发送请求前整批拒绝，避免超大批次占满内存。自动计划每个时刻执行一次原题。
- **记录保护与保留策略**：详情头部复制按钮旁可独立保护记录，历史页可选自定义天数或永久保留；缩短前预览，所有清理入口跳过保护记录。
- **生成期间的进度提示**：详情统一「查看详情」，生成期间显示紧凑的阶段、已用时间和剩余超时；指纹按采样计时，120 秒无有效数据只提醒，结束后隐藏进度提示。
- **原条件复测**：入口与本批次、历史批次标题对齐；手动批次可多选，自动历史一次复测所选模型、所选时刻的一条记录；指纹保留原题和原库，创建新的手动批次并保留来源。
- **失败原因与定向复测**：区分超时、限流、认证、响应中断、截断及答案不匹配等原因，保留原始错误；核对原条件后可按原因选择复测记录。
- **同目标近期趋势**：详情中展开最近 20 条同账号目标、同完整条件的记录；查看结果率、耗时和用量，以及有记录依据的连续异常或近期变慢提示。
- **备注与历史筛选**：详情直接显示备注输入框，点击「保存备注」保存；历史通过轻索引组合筛选备注、模型、账号、日期、结果及保护状态，不读取正文。
- **分类设置与清晰入口**：右上角主题按钮旁的「本地设置」分为运行提醒、请求控制、每日用量和配置迁移；历史筛选和保留时间分别打开独立面板。开始按钮有独立位置，切换页面时本地设置和主题保持固定。
- **用量统一展示**：三种测试均显示思考／输出 Token；接口尚未返回用量时显示流式字符数。
- **每个模型独立定时**：指定时刻或固定间隔，支持工作日、周末、自选星期和时区，每种测试每天最多 24 次。
- **修改计划保留结果**：同一模型、同一测试类型、同一原定执行分钟的已有结果可以复用，指定时刻与固定间隔互换也适用。
- **结果保存在本机**：默认保留 7 天，可修改保留策略，保存位置可直接打开；浅色和深色主题跟随宿主。

## 安装

需要 Magpie **0.1.2905 或更新版本**，并先在 Magpie 中配置至少一个可用供应商。插件附带固定版本的指纹 SDK，安装后无需额外运行构建或安装前端依赖。

### 本地安装包

从 [1.0.9 Release](https://github.com/xiaopeng66/magpie-model-lab/releases/tag/v1.0.9) 下载 `magpie-pelican-bench-1.0.9.zip` 并核对同页 SHA-256 校验文件。将 ZIP 解压到固定目录，在 Magpie 的插件页添加该目录。请选择**直接包含 `package.json` 的文件夹**，然后从侧栏打开“模型实验室”。

也可以在解压目录运行：

```powershell
magpie plugin add .
```

Windows 可使用 `tools/install.ps1`；Magpie 不在 PATH 中时，传入 `-MagpiePath` 指定可执行文件。

### 从 GitHub 安装

公开仓库：[xiaopeng66/magpie-model-lab](https://github.com/xiaopeng66/magpie-model-lab)。在 Magpie 插件发现的 GitHub 非官方区查找 `magpie-model-lab`，或使用：

```sh
magpie plugin add github:xiaopeng66/magpie-model-lab
```

可在仓库地址后加 `#v1.0.9` 固定安装本次正式版，也可从 [Releases](https://github.com/xiaopeng66/magpie-model-lab/releases) 下载 ZIP 安装包及 SHA-256 校验文件。GitHub 发现存在索引和缓存延迟，暂时搜不到时可直接按上面的命令安装。

公开版通过 GitHub 发布，npm 渠道暂未上线。完整规则见 [发布与发现指南](docs/publishing.md)。

技术包名和保存目录仍为 `magpie-pelican-bench`，升级沿用原有计划与历史。原地更新文件后，在 Magpie 插件页关闭再开启插件，重新打开页面即可加载新版本；页面刷新本身不能重载后台服务。

## 开始使用

1. 在“鹈鹕动画”“模型指纹”或“糖果测试”中选择供应商和模型。
2. 按需展开提示词与高级设置，点击顶部开始按钮。
3. 在卡片中查看结果；展开详情可查看原始回复、思考、参数和用量。
4. 需要持续观察时，进入“自动测试”添加模型，从卡片右上角设置计划并启用。
5. 在“历史记录”中查看以往批次、导出记录或清理文件。

| 默认设置 | 数值 |
| --- | --- |
| 最大输出 | **64000 Token**；设为 **0** 时省略插件提供的输出上限 |
| 生成超时 | **600 秒**；Token 上限旁可调，**0** 表示不设插件侧超时 |
| 手动批次并行数 | 动画 **2**，指纹／糖果 **3**；**0** 表示不设并行上限 |
| 自动测试并行数 | **3**，在管理模型页直接调整；**0** 表示不设并行上限 |
| 自动时刻数量 | 每模型、每测试类型、每计划日最多 **24 次** |
| 结果保留时间 | 默认 **7 天**，可设 **1–36500 天**或永久；保护记录跳过清理，模型和计划持续保留 |

旧模型已保存的参数继续保留，不会因升级重置为默认值。供应商与网关仍可能限制输出和并发。测试会使用所选供应商的额度。

## 使用须知

- 自动计划需要 Magpie 插件服务持续运行；休眠或退出期间错过的时刻不补跑，新计划默认暂停。
- 指纹提供参考库内的匹配证据，不能证明真实模型身份；糖果绿色表示最终数值匹配 21，不等同于完整推理验证或智商评分。
- 动画预览限制网络访问；模型依赖外部脚本、图片或字体时可能显示不完整。重播读取已保存文件，不再请求模型。
- 历史批次 JSON 用于留档和分析，单批采用 16 MiB 预算，超限时原始文件仍保留在保存位置；当前不提供历史恢复入口。配置迁移使用单独的配置 JSON。分享前请检查提示词、回复、账号标识与本机路径。

## 开发与许可

源码使用原生 HTML/CSS/JavaScript 与 Node/Bun，无前端构建步骤。Node 22+ 或 Bun 可独立调试：

```sh
node serve.mjs --port 3489 --data-dir .local-data --gateway http://127.0.0.1:3425
node --test tests/*.test.mjs
bun test ./tests
bun tools/check-static.mjs
```

测试使用临时目录与模拟网关。独立调试启动服务本身不发送模型请求；在页面开始测试或启用已有计划后才会使用配置的网关。
