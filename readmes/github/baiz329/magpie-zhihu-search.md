# 知乎搜索 · magpie 插件

[English](README_EN.md)

把知乎搜索接进 [magpie](https://github.com/yetone/magpie) 的联网搜索，
让智能体（Codex、Claude Code 等）在需要时能查知乎。

## 它提供什么

两个搜索入口，出现在 **设置 → 模型 → 联网搜索** 里：

| 入口 | 搜什么 | 每次最多 |
| --- | --- | --- |
| 知乎搜索 | 知乎站内：问题、回答、文章 | 10 条 |
| 知乎全网搜索 | 全网内容（可按站点、发布时间过滤） | 20 条 |

## 需要什么：Access Secret（登录一次）

去 [知乎数据开放平台](https://developer.zhihu.com/) 登录，
在个人中心新建一个 **Access Secret**。

装好插件后，去喜鹊的 **提供商** 页添加知乎账号，用这个 Access Secret 登录一次，
两个搜索入口共用这一个账号，不用各填一次。

- 未实名：每天 10 次；实名后：每天 5000 次（知乎的试用额度，试用结束需另行开通）
- 站内搜索和全网搜索的额度分开算，以个人中心的用量显示为准
- 剩余额度显示在提供商页的知乎账号卡片上，`magpie quota` 命令也能查；搜索密钥列表里看不到（喜鹊目前只在那给 Tavily 显示额度）

> 0.2.0 改动：登录方式变了。0.1.0 在两个搜索入口各填一次密钥的做法不再使用，
> 请在提供商页登录一次知乎账号；之前填过的搜索入口密钥会被忽略。

## 安装

在喜鹊里装这个仓库：

```sh
magpie plugin add github:baiz329/magpie-zhihu-search
```

也可以在插件页面点“添加插件”，填仓库地址。

装好后去 **提供商** 页添加知乎账号，用 Access Secret 登录一次；
再去 **设置 → 模型 → 联网搜索**，确认“知乎搜索”和“知乎全网搜索”两个入口都已启用。

## 怎么用

填好密钥后，把知乎移到搜索列表前面，
让智能体联网搜索一个问题，回答里出现知乎的结果就说明通了。

搜索是按列表顺序依次尝试的：
知乎限流或密钥不对时，喜鹊会自动换下一个搜索源，不会卡住。

## 它怎么工作

每次搜索向知乎发一个 GET 请求，
带上 `Authorization: Bearer <Access Secret>` 和一个秒级时间戳 `X-Request-Timestamp`，
把返回的标题、摘要、链接交给模型。
知乎的错误码会转成 HTTP 状态：限流（30001）当作 429，鉴权失败（20001）当作 401。

## 常见问题

- **搜不到知乎结果**：先确认插件已启用，并且 **设置 → 插件** 里“联网搜索”这个内置插件也是开着的；再确认提供商页的知乎账号已登录。
- **提示 401**：密钥不对或过期，去知乎个人中心重新建一个，到提供商页的知乎账号重新登录。
- **提示 429**：今天的次数用完了，等明天，或换一个密钥重新登录。
- **插件装不上**：确认仓库是公开的，并且 `package.json` 在仓库根目录。
- **想查还剩多少次**：去提供商页看知乎账号卡片上的额度，或跑 `magpie quota`；也可以去 [知乎个人中心](https://developer.zhihu.com/profile) 看用量统计，或调 `GET /api/v1/quota`（带上你的 Access Secret，不消耗额度）。

## 隐私

- 你的 Access Secret 只存在喜鹊本地，由喜鹊保管，只发给知乎，不发给别人。
- 搜索内容会发给知乎（不然搜不了），喜鹊会在日志里把搜索词遮住。
- 本插件不收集、不上传任何东西，也不在本地存任何数据。
