## 📖 简介

**Magpie OmO Setting** 是专为 [Magpie](https://github.com/magpie-ai/magpie) 桌面客户端与 [OmO](https://github.com/magpie-ai/omo) AI Coding Agent 打造的独立页面插件（Page Plugin）。

OmO 拥有强大的多代理协作、任务类别分工与思考档位控制能力，但日常维护 `~/.omo/omo.jsonc` 配置文件不仅繁琐，而且容易在保存时丢失手写注释。本插件为 Magpie 带来优雅的原生管理界面，让模型调优、子代理分配与多设备云端同步变得直观、可靠、零门槛。

---

## ✨ 功能特性

- 🎨 **原生页面体验**：深度集成至 Magpie 侧边栏「插件」分组，自适应跟随 Magpie 切换深色 / 浅色主题。
- ⚡ **类别配置 (Categories)**：
  - 直观调配 `ultrabrain`、`deep-low`、`deep-high`、`visual-engineering`、`quick`、`writing`、`artistry` 等任务类别的模型优先级。
  - 支持多级回退模型（Fallback Models）的添加、上下移排序与删除。
  - 细粒度调整推理档位（Reasoning / Thinking Effort：`off`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`, `auto` 及自定义档位）。
- 🤖 **子代理精细调优 (Subagents)**：
  - 完整支持四大核心命名子代理：`explore`（代码探索）、`librarian`（文档检索）、`plan-consultant`（方案咨询）、`plan-reviewer`（方案审查）。
  - 支持独立配置各子代理的主模型与推理档位；即使配置文件中尚未显式声明，界面也能自动补齐并在保存时按需写入。
- 📝 **无损 JSONC 读写与 CAS 保护**：
  - 基于 AST 局部替换与 Revision CAS（版本比对）机制。
  - 纯重排与模型调整仅操作原始代码切片，**完整保留原有注释（`//` 与 `/* */`）、空行及其他未纳管配置项**，彻底告别配置损坏。
- 🔌 **Magpie 本地网关联动**：
  - 实时从 Magpie 本地网关拉取已启用的模型列表，自动添加 `magpie/` 命名空间前缀。
  - 支持下拉搜索与快速选择，同时保留手动输入任意第三方自定义模型的灵活性。
- ☁️ **WebDAV 云端同步与多端备份**：
  - **零门槛复用**：一键继承 Magpie 客户端现有的坚果云 / WebDAV 凭据（自动读取 `~/.config/magpie/sync.json`）。
  - **自动静默增量同步**：后台每 3 分钟自动检查本地变更并同步至云端，无需频繁手动上传。
  - **智能冲突保护**：精确检测本地与远端版本差异，当双端同时修改时主动拦截，拒绝意外覆盖。
  - **历史版本快照**：云端恢复覆盖本地前自动生成带时间戳的历史备份，随时可安全回滚。

## 🚀 快速安装

### 前置要求
- **Magpie** 桌面客户端
- **[Bun](https://bun.sh)** (>= 1.0) 运行时

### 安装步骤

1. **克隆仓库至本地**：
   ```sh
   git clone https://github.com/xiaob1n/magpie-omo-setting.git
   ```

2. **安装依赖**：
   ```sh
   cd magpie-omo-setting
   bun install --frozen-lockfile
   ```

3. **添加至 Magpie 客户端**：
   - **方式 A（CLI 快速添加）**：
     ```sh
     magpie plugin add /path/to/magpie-omo-setting
     ```
   - **方式 B（图形界面添加）**：
     打开 Magpie 客户端 -> 进入「设置」->「插件」->「已安装」-> 点击「添加本地插件」选择该目录。

## 🖥️ 使用指南

### 1. 打开配置界面
插件启用后，在 Magpie 侧边栏「插件」分组下点击 **「OmO 设置」** 即可打开独立配置页面。

### 2. 调整模型与推理档位
- 点击类别或子代理卡片展开详情。
- 通过模型下拉列表选择网关模型，或直接在输入框中输入自定义模型标识。
- 通过「上移」「下移」调整模型回退优先级，通过「添加模型」「删除」管理备选列表。
- 切换或输入推理档位（Reasoning Effort）。
- 点击右上角或底部的 **保存配置**，配置即时原子写入本地 `~/.omo/omo.jsonc`。

### 3. 配置插件选项
若需要自定义插件本地服务的回环监听端口（默认 `3488`），可通过 Magpie CLI 设置：
```sh
magpie plugin options magpie-omo-setting '{"port": 3489}'
```
亦可通过环境变量 `MAGPIE_OMO_PORT=3489` 进行覆盖。

## ☁️ 云端同步 (WebDAV)

本插件提供开箱即用的 WebDAV 双向同步能力，非常适合在多台工作电脑（如办公室与家中设备）之间无缝保持 OmO 调优配置一致。

### 凭据配置
- **继承 Magpie 凭据（推荐）**：默认开启「复用 Magpie 坚果云配置」，直接共享 Magpie 自身的 WebDAV 同步凭据，免去重复配置。
- **自定义 WebDAV 服务器**：支持连接坚果云、Nextcloud、ownCloud 或任何标准 WebDAV 服务。可自由配置服务器 URL、用户名、应用专属密码及远端文件存储路径（默认 `magpie/omo/omo.jsonc`）。

### 同步机制与安全防护
- **每 3 分钟自动增量同步**：服务端在后台定时运行（即使配置页面未打开也持续工作）。若检测到本地有新改动且远端自上次同步未发生变更，会自动静默上传。
- **立即备份到云端**：随时点击可将本地当前配置即时上传至 WebDAV，保存状态无需二次确认。
- **从云端恢复与自动快照**：从远端拉取配置并覆盖本地。为保证数据安全，操作需要确认，且在覆盖前会自动在 `~/.omo/` 目录下生成历史快照（如 `omo.jsonc.bak.1700000000000`），并对下载的 JSONC 进行完整合法性验证后才执行原子写入。
- **敏感凭据脱敏**：独立凭据存储于 `~/.config/magpie/omo-webdav.json`，权限强制设置为 `0600`；API 接口绝不返回明文密码，密码输入框留空时自动沿用已保存密码。

## 🛡️ 架构与安全设计

```
┌────────────────────────────────────────────────────────┐
│                      Magpie 客户端                     │
│  ┌──────────────────────────────────────────────────┐  │
│  │ Opaque Iframe 前端沙箱 (ui/index.html)            │  │
│  └────────────────────────┬─────────────────────────┘  │
└───────────────────────────┼────────────────────────────┘
                            │ HTTP + Token 鉴权 (Origin: null)
┌───────────────────────────▼────────────────────────────┐
│              本地轻量 HTTP 服务 (index.mjs)            │
│  - 进程随机高强度安全 Token 校验                       │
│  - 严格 Host 白名单拦截与精确 CORS 白名单               │
├────────────────────────────────────────────────────────┤
│                     核心处理模块                       │
│  - lib/omo-config.mjs  AST 无损 JSONC 读写 & Revision CAS │
│  - lib/webdav.mjs      WebDAV 双向同步 & 冲突检测 & 自动备份│
│  - lib/gateway.mjs     Magpie 网关模型拉取与命名空间适配 │
├────────────────────────────────────────────────────────┤
│                       数据持久化                       │
│  - ~/.omo/omo.jsonc        OmO 核心配置文件             │
│  - ~/.config/magpie/       WebDAV 独立凭据 (mode 0600)  │
└────────────────────────────────────────────────────────┘
```

- **Opaque Iframe 跨域沙箱与 Token 鉴权**：
  插件界面加载在沙箱 Iframe 中，来源标记为 `Origin: null`。本地 HTTP 服务只放行携带本次启动动态生成的一次性高强度安全令牌（`X-Omo-Token`）的合法请求，并进行严格的 Host 头白名单校验，有效防御任意第三方恶意网页的跨站探测与 CSRF 攻击。
- **无损 AST 局部更新与 CAS 并发保护**：
  采用 `jsonc-parser` 精确定位修改节点的字节偏移量，不触碰未修改的 AST 分支；同时通过 SHA-256 计算文件 Revision 进行原子比对（CAS），避免并发或多进程写入导致的脏写覆盖。

## 🛠️ 开发与测试

本项目采用 [Bun](https://bun.sh) 作为运行时环境与测试执行器。

```sh
# 安装锁定依赖
bun install --frozen-lockfile

# 独立启动本地服务进行调试
bun index.mjs

# 执行完整的自动化测试套件
bun test
```

自动化测试已全面覆盖 40+ 关键用例：
- JSONC 读写：注释完整保留、字符串内标点与空白符处理、BOM 头兼容。
- 排序与更新：纯顺序重排时原文切片搬移、多模型增删、异常节点只读保护。
- WebDAV 同步：自动增量同步、双端冲突拦截、下载异常防御与目录自动递归创建。
- 服务安全：安全令牌生命周期、伪造 Host/Origin 拦截、CAS 版本保护与密码脱敏。

## ❓ 常见问题 (FAQ)

### Q1: 页面一直停在「正在连接 OmO 设置服务…」无法加载？
**A**: 页面插件界面的配置读写依赖于由 Bun 驱动的本地轻量级服务。通过本地文件夹添加插件时，若 Magpie 尚未初始化用于插件宿主的 Bun 环境，可能导致服务未能成功启动。

**排查与解决办法（任选其一）**：
1. **自动补齐**：在 Magpie 中添加任意一个 npm 插件（例如 `@magpie-community/middleware-model-map`），Magpie 会顺带自动下载并配置内置的 Bun 环境；
2. **指定系统 Bun**：在终端执行以下命令直接指定系统已安装的 Bun 路径：
   ```sh
   launchctl setenv MAGPIE_BUN "$HOME/.bun/bin/bun"
   ```
   配置后**重启 Magpie 客户端**，然后在插件管理页面将本插件关闭后再重新打开即可正常加载。

### Q2: 保存配置后会丢失我在 `omo.jsonc` 中手写的注释吗？
**A**: **完全不会**。插件内部使用了无损 AST 局部更新与原文切片搬移算法，无论对模型进行编辑还是上下调换顺序，原有的行内注释 `//`、块级注释 `/* */` 以及原有换行缩进都会原汁原味地保留。

### Q3: 为什么部分旧类别（Legacy）的模型无法直接编辑？
**A**: 如果在 `omo.jsonc` 中检测到旧版本格式（例如直接使用了 `model` 字符串或 `fallback_models` 数组），为了避免破坏不兼容的旧结构，插件会将该项的模型列表置为只读模式以确保安全。此时推理档位仍可自由调整；如需使用新版模型链列表，建议更新为标配的 `models: [...]` 数组格式。
