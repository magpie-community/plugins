# Magpie Prompt Hub

**Magpie 的本地 PromptHub。** 在侧栏集中保存常用提示词，随时查找并复制到其他应用。

## 安装与加载

安装 Magpie 后，在本项目目录运行以下命令。

```sh
magpie plugin add .
```

在 Magpie 侧栏「插件」分组打开「PromptHub」。

## 使用方法

![PromptHub 主界面，左侧是分类和标签，中间是提示词列表，右侧显示完整正文](./assets/screenshots/library.png)

### 新建与编辑

点击「新建」，填写标题和正文，按需选择分类、添加标签或设为收藏，再点击「保存」。打开已有提示词后，可以直接编辑、收藏或删除。要新增或调整分类，点击左侧「分类」旁的「管理」。

![新建提示词表单，已填写标题、分类、标签和多行正文](./assets/screenshots/editor.png)

### 查找与复制

- 在顶部搜索标题或正文，例如输入「周报」找到「周报润色」。也可以按分类、标签或收藏缩小结果。
- 打开结果后点击「复制正文」，即可将完整提示词粘贴到其他应用。
- 按 `Ctrl/⌘ + K` 打开「快速跳转」，选中结果后按 Enter 打开，或按 `Ctrl/⌘ + Enter` 直接复制。

### 备份与恢复

打开「备份与恢复 (JSON)」，可将备份导出到下载目录。恢复时选择 JSON 文件，查看新增和跳过的条目数，再点击「确认合并导入」。

提示词和主题偏好保存在本机，核心功能可离线使用。主题默认跟随 Magpie，可通过右上角按钮切换。备份为明文 JSON。

## 开发

运行 `node dev.mjs` 启动本地预览，在浏览器打开终端显示的地址。运行 `npm test` 执行测试。
