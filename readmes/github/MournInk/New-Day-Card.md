# 每日用量卡 (Day Card)

把枯燥的 AI Token 账单，打印成一张带撕口、折痕和油墨质感的热敏小票。

这是为 [magpie](https://usemagpie.ai) 制作的账单卡片插件。不管你是想看看今天在哪个模型上烧了多少钱，还是想拉出过去一个月甚至全部时间的累计总账，它都能帮你排成一张像模像样的收银条——调好纸张和背景，一键就能复制或存成高清图片发给朋友。

---

## 核心特性

### 🧾 一目了然的 AI 账单
- **多周期统计**：支持按 **日 / 周 / 月 / 全部时间** 查看。除了单日流水，还能汇总活跃天数与日均开销。
- **开销与排行**：按 API 价格折算总花费，对比平时日均水平；自动按花费列出各 Agent 与所用模型明细（带专属图标）。
- **Token 细项**：汇总总吞吐量、输入与输出拆分，以及一眼看清省了多少钱的 **缓存命中率**。
- **实时刷新**：停留在「今天」时，账单会每分钟自动更新最新用量。

### 🖨️ 拟真热敏纸与做旧手感
- **纸张色调**：从刚出打印机的冷白新纸，到揣在钱包里放了一个夏天的发黄旧纸，字迹也会随纸张变旧而自然发淡。
- **打印失真**：还原老旧热敏打印头的物理瑕疵——笔画边缘的毛刺、轻微断针白线、走纸错位、行间浓淡起伏以及粗体字边缘的洇墨。想要干净利落的现代感，把滑块拉到 `0` 即可。
- **口袋折痕**：模拟小票折好塞进口袋又展开的痕迹，包含山折与谷折的明暗过渡、涂层裂开的白纹以及纸边的微小折口，折痕深浅可自由调节。
- **每日独一无二**：同一天、同一周期的小票，其纸纹、顶部与底部的撕口形状、折痕位置和打印瑕疵都是固定绑定的，不会每次刷新都变样。

### 🖼️ 丰富背景与高清导出
- **内置底纹与照片**：自带 15 款质感底纹（青绿、野餐格、方格纸、牛皮纸、蓝晒、青海波、宣纸等）和 4 张风景照片。
- **自定义与透明底**：支持直接上传、拖入或 `Ctrl/Cmd + V` 粘贴自己的图片作为背景，并可调节边距、模糊度和暗度；选择「无背景」则可直接导出带阴影的透明底 PNG。
- **超采样输出**：页面内会自动缩放以适应窗口预览，但点击 **复制图片** 或 **保存 PNG** 时，始终输出 2~3 倍分辨率的原尺寸高清大图。

## 安装与使用

### 1. 安装插件

将本仓库克隆到本地后，通过 magpie CLI 添加插件：

```sh
git clone https://github.com/MournInk/New-Day-Card.git
magpie plugin add ./New-Day-Card
```

安装完成后，打开 magpie 客户端（或 `magpie web`），在左侧边栏的 **插件** 列表下即可找到 **每日用量卡**。插件界面与小票语言会自动跟随系统语言（支持简繁中文、英语、日语、德语）。

> **版本要求**：本插件依赖较新的 magpie 接口（`>= 0.1.3427`）。如果打开页面或切换「周 / 月 / 全部」时收到提示，请先将 magpie 更新到最新版本。

### 2. 日常使用

1. **选定时间**：在左上角切换「日 / 周 / 月 / 全部」，用左右箭头翻页，或直接点击日期下拉菜单跳转到任意有调用记录的日子。
2. **调整样式**：在顶部工具栏挑选喜欢的背景，按喜好微调纸张发黄程度、打印失真度与折痕深浅（所有外观偏好都会自动保存，下次打开无需重调）。
3. **分享账单**：点击右上角的 **复制图片** 直接粘贴到聊天窗口，或点击 **保存 PNG** 存入本地下载目录。

## 隐私与安全

我们非常看重你的数据安全：

- **最小只读权限**：插件仅声明并读取 `usage:day` 这一项汇总数据（仅包含用量统计数字与 Agent 图标），**绝不接触**任何 API 密钥、账号信息、对话上下文或 Prompt 内容。
- **纯本地离线渲染**：小票完全在本地无网络权限的沙盒环境中绘制与生成，没有任何外部网络请求，数据不会离开你的设备。
