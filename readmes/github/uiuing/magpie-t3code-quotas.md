# magpie-t3code-quotas

极简的 **Magpie 插件**，让你在 **T3 Code 的 `Usage → Limits`** 里直接查看 Magpie 各账号的剩余额度与多账号汇总。

- **零改源码**：不改 Magpie 本体，也不改 T3 Code 本体，纯薄适配层。
- **零第三方依赖**：纯 ES Modules + Node/Bun 内置 API。
- **装完自动接入**：自动写入 `~/.t3/userdata/settings.json`（兼容 `$T3CODE_HOME`），T3 Code 自动热加载，无需手动填表；并正确识别 T3 Code 对密钥的加密脱敏（`••••••`），重启不再反复要求重新同步。
- **安全隔离**：首次启动自动生成高熵随机连接密钥；仅监听 `127.0.0.1`、严格校验 `Host` 头防 DNS rebinding，控制页接口校验每次启动生成的随机 `X-UI-Token`，绝不触碰任何 OAuth Token。

---

## 安装方式

### 在 Magpie 中安装（推荐）

打开 Magpie → **Plugins（插件）** 添加，或执行：

```sh
magpie plugin add github:uiuing/magpie-t3code-quotas
```

安装开启后：
- 插件自动随 Magpie 启动并写入 T3 Code 配置，直接去 T3 Code 按 `⌘U`（`Usage → Limits`）或输入 `/usage-limits` 即可查看额度。
- Magpie 左侧栏会出现 **「T3 Code 额度」** 控制页，所有预设与勾选立即生效。

### 独立命令行运行（可选）

```sh
bun serve.mjs
# 或
node serve.mjs
```

支持环境变量：`PORT`、`MANAGEMENT_KEY`、`MAGPIE_ADDR` / `MAGPIE_URL`、`MAGPIE_API_KEY`、`KEPT_ONLY`。

## 核心功能

1. **一键场景预设（开箱即用，无需研究复杂参数）**
   - **多账号全览（推荐）**：各账号独立传给 T3 Code，由 T3 Code 自动按厂商与模型池拼成多段进度条，鼠标悬停查看每个号各自余量与回血时间。
   - **同套餐合成一条**：同一套餐下选中的账号合并成一条总余量，画面最紧凑；默认仅当全套餐重置时间相差不超过合并窗口时才传重置时间，避免误导。
   - **只看正在用的号**：每个厂商只同步 Magpie 最近实际服务过请求的账号，账号多时最清爽。
   - 端口、Magpie 远程地址、缓存策略等低频项收纳在「高级设置」折叠区。

2. **可自定义「重置时间合并窗口」（默认 5 分钟，精确到秒）**
   - 支持在高级设置中按 **秒 / 分钟** 自定义（`0` 秒～`24` 小时，`0` 表示严格不合并），并提供 `0秒 / 10秒 / 30秒 / 1分 / 5分 / 15分` 快捷切换。
   - 相差不超过合并窗口的账号自动归为同一波回血：全部账号同步重置时直接显示 `x 小时后全部重置`，分批重置时清晰标出 `x 小时回血 m/n 号 (+y%) / 全重置 z 小时`。
   - 与「同套餐合成一条」模式联动，避免把单号重置误当成全部重置。

3. **双视图看额度 + 快捷筛选**
   - **按厂商与套餐（同步选择）**：支持按厂商、按套餐一键勾选及展开微调单号，并提供「全部同步」「只选各家主力套餐」「只选正在用的号」「全部取消」快捷操作。
   - **按模型看（跨厂商对照）**：将 Claude、Codex / GPT、Gemini、Grok 等跨厂商渠道按模型家族并排对照展示（不强行跨厂相加百分比），一眼看出当前哪条渠道还能用。

4. **页面内直接热切换端口**
   - 在高级设置中直接输入新端口并点击「切换端口」：先试绑定新端口（被占用时报错不中断原服务），绑定成功后自动更新 `plugins.json` 与 T3 Code 配置并跳转。
   - 若启动时端口被占用，超时兜底页也支持直接换端口重试。

## 支持范围与说明

- **T3 Code 原生 `Usage → Limits` 范围**：受 T3 Code 服务端白名单限制，原生显示 **Claude、Codex (ChatGPT)、Antigravity、Grok** 四类订阅账号（支持多账号、多套餐与 Remote Magpie 账号）。
- **其他厂商额度**：WorkBuddy、DeepSeek、Kimi、GLM、MiniMax 及 API Key 余额会在控制页的「按模型看」与底部「其他厂商额度」中汇总展示。
- **远程 T3 Code 接入**：服务仅监听 `127.0.0.1`；若 T3 Code 在另一台电脑，请在控制页展开「连接密钥与远程设备手动接入」复制 SSH 隧道命令后手动添加到 T3 Code。
