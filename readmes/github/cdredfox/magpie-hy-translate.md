# Magpie Tencent Hy Translate

[简体中文](README.md) | [English](README.en.md)

直接调用 Chrome 扩展「腾讯 Hy 翻译」背后的腾讯混元翻译服务，无须部署 API 服务、Docker 或额外 API Key，也无须登录腾讯账号——服务本身支持匿名登录，插件自动完成。

## 直接安装（远端也适用）

在 Magpie「插件 → 发现」底部的安装框填写本仓库：

    github:cdredfox/magpie-hy-translate

也可以在运行 Magpie 的机器上使用 CLI：

    magpie plugin add github:cdredfox/magpie-hy-translate
    magpie plugin login txhy-translate

登录时**直接回车即可**：服务是匿名登录，插件自动生成设备 ID、换取并续期凭据，不需要腾讯账号、Cookie、API Key 或打开浏览器。登录时会实际调用一次翻译验证连通性。凭据保存在 Magpie 配置目录的 `plugin-auth.json`（权限 600）；请勿分享此文件。

更新插件后，在 Magpie 中更新插件，或运行 `magpie plugin update`。

## 模型与翻译

| 模型 | 说明 |
| --- | --- |
| `txhy-translate/hy` | 腾讯 Hy 翻译（默认：网页翻译场景） |
| `txhy-translate/hy:selection` | 划词翻译场景 |
| `txhy-translate/hy:word` | 划词（单词）场景，返回简明词义 |
| `txhy-translate/hy:sidebar` | 侧边栏场景 |

后缀 `@风格` 可指定翻译风格：`academic`（论文）、`casual`（口语）、`science`（科普）、`business`（商务）、`news`（新闻）、`promo`（营销文案）、`novel`（小说）、`legal`（法律合同），例如 `txhy-translate/hy:selection@academic`。

通过腾讯混元翻译网页接口调用，请求参数与官方 Chrome 扩展逐字段一致。供应商使用 Chat Completions，Magpie 负责转换客户端协议。默认目标语言为简体中文；系统提示词或指令中的明确翻译指令（如「翻译成英语」）优先于插件默认值。只翻译最后一条 user 文本，不支持对话记忆、图片、工具、推理或结构化输出。请在翻译客户端显式选择上述模型，避免将其用于聊天、编程或自动路由的通用任务。

支持的语言：`zh`（简体中文）、`zh-TR`（繁体中文）、`yue`、`en`、`ja`、`ko`、`fr`、`de`、`es`、`pt`、`ru`、`ar`、`it`、`th`、`tr`、`vi`、`ms`、`id`、`fil`、`hi`、`pl`、`cs`、`nl`、`km`、`my`、`fa`、`gu`、`ur`、`te`、`mr`、`he`、`bn`、`ta`、`uk`、`bo`、`kk`、`mn`、`ug`。常见别名（`zh-TW`、`zh-Hant`、`pt-BR` 等）自动映射。

多段文本按空行分段逐段翻译，全部成功后按原顺序合并返回。流式请求在完整翻译成功后输出 SSE，不是逐 token 实时翻译。token usage 为 0，未提供可验证的上游额度，不上报虚构用量。插件不保存原文、译文或独立统计文件。

## 检测

    magpie provider test txhy-translate hy

该命令验证连通性，翻译验收还应明确发送目标语言和原文。

单元测试：

    bun test

## 工作方式

magpie 只会说四种 LLM API；上游是单段文本翻译接口（`POST /api/v1/translate`）。本插件注册一个 chat-completions 供应商，把进来的 chat 请求解码成待翻译文本（剥离指令行、按空行分段），逐段调用翻译接口，再把结果拼回 chat-completions 流式（或非流式）响应。请求头（`accept: text/event-stream`、`cache-control: no-cache`、`X-Source: pc_plugin`、`X-ID`、`X-Token`）、请求体（`source_text`、`source_language`、`target_language`、`scene`、可选 `style`）与扩展完全一致。

凭据过期时插件自动重新匿名登录（同一设备 ID）；token 被拒绝时自动重试一次。翻译失败的空响应会按登录过期标记（`X-Magpie-Sign-In: expired`）上报。HTTP 429 保留为 429，其他失败使用兼容 API 错误格式。代理使用 Magpie 的账号/供应商代理配置。

当前通过本地文件夹或 GitHub 仓库安装，未发布到 npm 或插件推荐市场。
