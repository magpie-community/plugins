# Magpie 用量与订阅

Magpie 社区插件。按供应商、账号和模型查看调用量、Token 与预估费用，同时查看账号当前额度、余额和重置时间。用量和额度可组合成日报、周报等纯文字报表，定时发到 Telegram、QQ、邮箱或 Webhook。

## 安装

要求 Magpie **0.1.3436+** 和 **Bun 1.3.0+** 插件宿主。Magpie 会在首次添加插件时下载 Bun。 [Magpie 插件文档](https://usemagpie.ai/docs/plugins)

```sh
magpie plugin add github:lucklyduck/magpie-usage-reporter
```

也可以在 Magpie 的 **插件 → 添加插件** 中输入 `github:lucklyduck/magpie-usage-reporter`。启用后，在侧栏的 **插件** 分组打开 **用量与订阅**，即可查看当前网关已有的用量记录。页面随宿主切换浅色或深色主题，也支持 `magpie web` 的插件服务代理。

从本地源码安装时，在仓库目录运行 `bun install`，然后在 **添加插件** 中填入该目录的路径。

## 使用

### 查看用量

- 用 **按账号** 和 **按模型** 切换归类。树表分别以「供应商 → 账号 → 模型」和「供应商 → 模型 → 账号」排列。点击行名展开明细，也可一键展开或收起。
- 周期可选 **今日**、**近七天**、**近30天** 和 **自选日期**。排序可选 Token、费用、调用量和名称。
- 在 **筛选与显示列** 中按供应商、账号、模型、Agent 或记录来源筛选，并选择要显示的指标。可用指标包括失败、重试、取消、输入与输出 Token、缓存读写、推理 Token 和平均首 Token 延迟。
- **Token 含缓存** 会一起更新总量和占比条。供应商显示占当前筛选总量的比例，下面每一层显示占上一级的比例。
- **显示无调用账号** 和 **显示 0 用量模型和供应商** 默认开启，可分别调整。概览的供应商数始终统计可用供应商。点击 **保存为默认显示** 可保留常用的显示偏好。

### 创建一份订阅

1. 在 **通知渠道** 添加并保存渠道。点击 **发送测试**，按提示确认后到接收端核对消息。
2. 在 **订阅** 选择一个预设，比如 **每日综合日报**，再点击 **新建订阅**。选择一个主渠道，也可以指定一个备用渠道。
3. 设置时区、发送时间和报告内容。例如每天 22:00 推送今日账号用量、本周模型排行和当前额度。
4. 点击 **预览** 核对文字和消息条数，然后保存。新订阅默认停用，确认后可启用定时发送，也可用 **立即发送** 单独投递一次。
5. 在 **发送记录** 查看报表、各分片的确认情况及失败原因。

报表可包含用量概览、账号用量表、模型用量表、当前额度、余额和重置时间。可限定统计范围、隐藏账号名称，并为每个用量区块选择周期、指标列、排序和前 N 行。布局支持等宽表格、详细列表与简短摘要，长消息会按渠道限制拆分。 [订阅配置示例](examples/subscriptions.example.json)

### 定时发送与重试

- 支持间隔、每日、每周、每月和五字段 cron。页面关闭后，调度继续随 Magpie 插件宿主运行。宿主停机或设备休眠期间错过的计划，恢复后默认补最近一次，也可在订阅中选择跳过。
- 主渠道尚无已确认的分片时，明确的永久失败或临时失败重试耗尽会触发备用渠道。临时失败最多尝试三次。已有分片确认时，剩余内容继续使用同一渠道。
- 状态为 **结果未知** 时，发送任务暂停。先在接收端核对，再决定是否在 **发送记录** 中手动重试。重试会复用原报表，从未确认的分片继续。

## 通知渠道

| 渠道           | 所需配置                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------ |
| Telegram       | Bot Token、Chat ID，可选话题 ID。支持私聊或群组。                                                                  |
| OneBot 11 HTTP | OneBot 服务的 HTTP 地址、私聊或群聊目标 ID，可选 Access Token。                                                    |
| SMTP 邮件      | SMTP 主机、端口、发件和收件地址，以及邮箱服务要求的登录凭据。支持隐式 TLS（通常为 465）和 STARTTLS（通常为 587）。 |
| 通用 Webhook   | 接收 JSON 的 HTTP(S) POST 地址，可选 Bearer Token。                                                                |

Webhook 用 `reportId` 关联同一份报表的各条消息，`part` 从 1 开始计数。

```json
{
  "title": "每日综合日报",
  "text": "今日用量 · 98 次调用 · 125.4 万 Token",
  "reportId": "example-report-id",
  "part": 1,
  "totalParts": 1,
  "format": "text"
}
```

## 数据与设置

- **统计口径** 用量来自当前 Magpie 网关的匹配请求账本，按记录时间和所选时区归入周期。账号转交中的尝试计入 Token 和费用，调用次数以最终尝试为准。费用沿用 Magpie 的估算，缺少价格的调用标为「未定价」，实际支出以供应商账单为准。单次查询最多扫描 100 万条记录，达到上限时可缩短周期。
- **额度和余额** 卡片显示账号当前状态及网关读取时间。余额保留供应商的币种或单位，共用的额度或余额会标记为共享。
- **显示设置** 新安装默认跟随宿主的币种、数字单位和汇率缓存。可在 **设置 → 显示设置** 切换为自定义。新建订阅以当时的显示格式为默认值，保存后的报表格式由该订阅独立管理。
- **网关与端口** 默认使用宿主提供的网关地址。远程网关可在 **设置 → 常规设置** 指定，并通过宿主环境变量 `MAGPIE_API_KEY` 或 `MAGPIE_GATEWAY_KEY` 提供有权读取用量与额度的密钥。插件服务默认监听 `127.0.0.1:3495`，端口冲突时可在 Magpie 的插件选项中调整 `port`。
- **本地存储** 订阅和发送记录保存在 Magpie 配置目录下的 `usage-subscriptions/state.sqlite`。渠道凭据单独保存在同目录的 `credentials/` 中，由本地文件权限保护。迁移时一并保管 SQLite 的一致性备份和凭据目录。

## 开发

在仓库根目录安装依赖并运行检查。浏览器测试默认使用已安装的 Microsoft Edge，也可通过 `BROWSER_CHANNEL` 指定其他已安装的 Chromium 浏览器。

```sh
bun install
bun run typecheck
bun run test
bun run test:ui
```

独立预览使用工作区的 `.state`，并关闭调度。

```sh
bun serve.mjs --port 3496 --state-dir .state --no-scheduler
```

启动后访问 [http://127.0.0.1:3496](http://127.0.0.1:3496)。可用 `--gateway` 指定预览所读的 Magpie 网关。

`bun run test:live` 可对网关进行只读核对。`bun run pack` 会在 `outputs/` 生成安装包和依赖许可证清单。 [本地 API](docs/API.md) · [宿主验收记录](docs/ACCEPTANCE.md) · [GitHub Issues](https://github.com/lucklyduck/magpie-usage-reporter/issues)
