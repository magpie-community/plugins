## ✨ What You Get

### 🎁 Free Model Pools
The plugin gathers free models into a pool and lets you pick from that pool instead of hunting for each model separately. When one model in the pool is busy or unavailable, the pool can move on to the next one so your work keeps flowing.

### 🔐 EAC Authorization
EAC authorization is built in. It confirms that your setup is allowed to use the plugin's features, and it does so quietly in the background — no extra password screens, no complicated tokens to copy and paste.

### 👥 Multiple Account Providers
You can add several account providers at the same time and switch between them whenever you like. This is handy if you use more than one account for different tasks, or if you want a backup provider ready in case one stops responding. Each provider is listed separately, so nothing gets mixed up.

### ⚙️ Automatic Service Management
The services the plugin relies on are managed for you. They start when they are needed and shut down when they are not. You will not have to open a terminal, run a command, or remember to close something before shutting your computer down.

### 🖥️ Accountless Cloudflare Remote Console
The plugin can open a temporary Cloudflare remote console. "Accountless" means you do not need to create a Cloudflare account or sign in anywhere — the console simply appears when you ask for it and goes away when you are done. This is useful when you want to check on things from another device or from a different network without setting up anything permanent.

## 🛠️ Troubleshooting

**Magpie does not show the plugin.** Close Magpie completely, reopen it, and check the plugin list again. Confirm you pointed Magpie at the correct folder — the one that contains the plugin files, not a folder above it.

**The model pool looks empty.** Wait a moment and refresh the view. Pool contents can take a short while to appear on a first run.

**Account providers are not responding.** Switch to a different provider in the list to confirm the plugin itself is working, then return to the original one.

**The remote console address does not open.** Temporary addresses expire. Close the console and open it again to generate a fresh one.

**Services keep stopping.** Automatic service management may be reacting to something else on the computer. Restart the plugin and check again after a minute.
