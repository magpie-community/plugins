# 连接手机 · Magpie Connect Phone

这是 Magpie 手机版的 macOS 配套插件，用于让手机与 Mac 配对。安装后，在 Magpie 侧栏打开「连接手机」。

The macOS companion plugin for pairing Magpie Mobile with your Mac.

## 安装

在 macOS Magpie 的「插件 → 发现」中搜索「连接手机」或 `magpie-connect-phone`。也可从「添加插件」安装 `github:AndyChen1024/magpie-connect-phone`。

插件、手机端及中继的使用要求见 [Magpie Mobile 连接说明](https://github.com/AndyChen1024/magpie-mobile/blob/6fec223c0ef8af3ece8bafbd4f4b9e31595ee4b9/magpie-plugin/README.md)。

## 源码

此仓库分发 Mac 插件。插件源码和 Android、iOS 客户端在 [Magpie Mobile](https://github.com/AndyChen1024/magpie-mobile) 开发。本版插件 `0.1.1-alpha.1` 来自 [Magpie Mobile 提交 `6fec223`](https://github.com/AndyChen1024/magpie-mobile/tree/6fec223c0ef8af3ece8bafbd4f4b9e31595ee4b9/magpie-plugin)。
