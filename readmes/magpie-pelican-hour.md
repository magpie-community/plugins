# 鹈鹕巡检

插件在喜鹊内定时检测 Codex 官方供应商中启用的每个订阅账号。打开喜鹊侧栏的「鹈鹕巡检」，或访问[本机监测网页](http://localhost:18765/)。选择账号即可查看本机时间、最近一次检测、成功或失败的运行记录，以及已保存的动画。

监测页支持简体中文、繁體中文、English、日本語和 Deutsch。首次打开跟随系统语言，未匹配时显示简体中文。右上角可切换语言或恢复跟随系统。账号别名、固定提示词、模型原文和既有作品保持原文。

## 安装

在喜鹊中打开「插件」，按 npm 包名 `magpie-pelican-hour` 添加，或在已配置喜鹊 CLI 的终端运行：

```sh
magpie plugin add npm:magpie-pelican-hour
```

启用后，插件通过喜鹊已登录的 Codex 账号发出实际生成请求，消耗相应账号的订阅额度。可在侧栏「鹈鹕巡检」暂停单个账号。已验证的平台为 macOS；生成动态缩略图使用本机的 Google Chrome 与 FFmpeg。

## 使用

在喜鹊的插件设置中启用本插件。打开喜鹊并让电脑保持唤醒，调度和网页服务会随插件启动。关闭插件或退出喜鹊会停止服务，重新启用后可以继续浏览原有记录。

默认情况下，每个启用的账号在每小时的第 01 至 59 分钟之间随机安排一次检测。正常连续运行时，下一小时的计划分钟与本次实际开始的分钟最多相差 10 分钟，两次检测约间隔 50 至 70 分钟。选择账号可查看它的下次检测时间。计划保存在本机，重启后沿用。电脑休眠错过的往期小时会跳过。

插件每小时更新账号列表，并在准备发起检测时核对账号状态。新增并启用的账号自动加入。已移除或停用的账号保留历史记录。

每张账号卡片右侧都有「定时检测」开关。开启时会发起一次检测，之后约每小时检测一次。关闭时直接暂停，并取消该账号排队中的开启检测。历史记录保存在对应账号下。

账号卡片下的「免打扰与休息日」默认展开。打开「启用免打扰」胶囊开关。点开始或结束时间，滚动表盘到所需时刻，点「完成」，再点「保存设置」。设置对全部账号生效，每天按运行喜鹊的电脑所在时区执行，支持跨午夜。进入免打扰时插件暂停账号巡检、中断本机正在进行的检测请求，并跳过该时段的定时任务。在免打扰期间打开账号，开启检测会等到时段结束后执行。期间再关闭账号就取消这次检测。设置和账号开关状态保存在本机，重启后继续生效。

## 地区日历与休息日抽样

在「免打扰与休息日」打开「按地区日历抽样」，为每个账号选择每天 1 至 8 次。工作日和调休补班日沿用约每小时一次。休息日可选「均匀分布」，插件把免打扰以外的时间等分，每段安排一次，各账号的时刻独立生成。也可选「自选时刻」，逐个点时间胶囊设置。保存后，切换账号即可看到当天或下一个休息日的计划。账号暂停优先，手动开启时的单次检测单独记录。

次数按运行喜鹊的电脑所在时区的自然日统计，定时检测发起即计一次。当日改设置会计入已发起的定时检测。拥堵时，只在下一档、免打扰或当天结束前短暂排队，最多延迟一小时。关机或休眠错过的旧档不会集中补测。

在「休息日日历」中可跟随语言地区（例如 en-GB 或 en-US），也可指定地区。点选今天或未来的日期可在休息日和工作日之间切换，再点一次恢复地区默认值。可逐月翻页。点「保存设置」后，所有账号按新日历调度；自定义日期优先于地区日历。

日历随插件离线提供。中国大陆使用 2026、2027 年已公布的放假和调休安排。其他 245 个国家和地区使用 [python-holidays 0.109](https://github.com/vacanza/holidays) 的地区级公共假日规则生成 2026–2028 年日期，不同州省、学校或单位的差异可自行点选。未收录地区或年份按周末安排，并在日历提示。夏令时跳过的自选时刻当天略过，重复的时刻只抽样一次。中国大陆数据来源见[国务院办公厅 2026 年安排](https://www.beijing.gov.cn/cs/gncs/zcwj/202603/t20260327_4568275.html)和[国务院办公厅 2027 年安排](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)。

## 检测方式

插件通过喜鹊本机网关固定到具体账号，以模型 `gpt-6.2-astra` 和思考强度 `xhigh` 发送包内 `input.txt` 的固定提示词。各次请求独立，最多同时检测 3 个账号。详情里可查看原始回复、原始 HTML、提取的 SVG 和动画预览。在运行详情里点「模型原文」即可阅读回复，点「返回运行详情」可回到同一条记录。生成回复以 JSON 字符串携带完整 HTML 时，插件会先解码再提取。

画廊为含脚本的作品录制 60 帧/秒的静音视频预览。限制视频自动播放的浏览器使用 30 帧/秒的动画 PNG。缩略图进入视口后播放。录制使用本机的 Chrome 和 FFmpeg。缺少录制工具时仍会保存 HTML、SVG 和预览页。

## 从源码安装与本机存储

此目录是完整的本地喜鹊插件包。将整目录放在固定位置，再用喜鹊的本地插件安装功能选择该目录，或在此目录执行以下命令。

```sh
/Applications/magpie.app/Contents/MacOS/magpie plugin add "$PWD"
```

代码、提示词和监测页随插件分发。定时器、请求和 HTTP 服务运行在喜鹊自带的 Bun 宿主内。HTTP 服务监听 18765 端口。可访问该端口的局域网设备能以只读方式查看账号别名、运行记录和保存的输出。监测设置只接受来自本机页面的修改。插件通过喜鹊本机网关使用已有登录，会话凭据由喜鹊管理。

macOS 默认把归档放在 `~/Library/Application Support/magpie-pelican/`。若设置了 `XDG_DATA_HOME`，则使用该目录下的 `magpie-pelican/`。备份或迁移时可复制整个数据目录。账号别名可在喜鹊中修改，历史记录按固定的账号标识归档。
