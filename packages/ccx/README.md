# AutoBits AI Hub 供应商（ccx）

给 `https://ccx.autobits.cc` 的 Magpie 供应商插件，支持：
- 模型调用（OpenAI 兼容 API）
- 钱包余额读取
- **每日签到领积分**

## 怎么在 Magpie 里用

### 1. 添加供应商

打开 Magpie → 供应商 → 添加 → 找到 **AutoBits AI Hub**。

### 2. 登录账号

两种方式：

**方式一：API Key（推荐）**
- 在 AutoBits 控制台 → 密钥管理 → 创建 API Key
- 在 Magpie 里选「API Key（推荐，可自动签到）」，粘贴 Key
- 这个 Key 同时用于调模型和签到

**方式二：浏览器登录**
- 选「浏览器登录（没有 API Key 时使用）」
- 会打开 Edge 或 Chrome，手动登录（密码/验证码/通行密钥）
- 登录成功后窗口自动关闭，登录状态保存

### 3. 每日签到

- 在 Magpie 的「用量」页面，AutoBits 账号卡片上会显示「每日签到」状态
- 点「立即签到」按钮手动签到
- 或在「设置 → 用量」里打开 AutoBits 的「每日签到」开关，让它每天自动签到

### 4. 多账号

- 每个账号独立登录，独立浏览器配置，不会串号
- 在 Magpie 里可以添加多个 AutoBits 账号，各自独立签到

## 复用已有登录状态

如果你之前用过 `~/ccx-checkin` 独立签到工具，Magpie 会**自动复用**那里的登录状态，不用重新登录。

支持的账号名：`主号`、`2407241392`、`Mcnuldy`、`Wal` 等（你 `~/ccx-checkin/profiles/` 下的目录名）。

## 技术说明

- 签到通过**真实浏览器**完成（Edge/Chrome），不是硬发 API 请求，避免鉴权问题
- 浏览器使用**私有管道**通信，不开放调试端口，其他程序无法连接
- 每个账号有独立的浏览器 profile 和锁，多进程不会冲突
- 签到结果分类：已领取 / 今天已签 / 活动未开放 / 需要重新登录 / 需要到官网完成验证

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.mjs` | 插件入口：供应商定义、登录方式、签到钩子 |
| `lib/session.mjs` | 浏览器会话管理：启动、登录、签到、读余额 |
| `lib/page.mjs` | 页面操作：等加载、找按钮、点签到 |
| `lib/cdp.mjs` | Chrome DevTools Protocol 私有管道客户端 |
| `lib/lock.mjs` | 跨进程锁，防止多实例冲突 |

## 注意

- 签到每天只能领一次，重复点会显示「今天已签」
- 浏览器 profile 里存着登录凭证，不要外传
- 这类自动签到可能违反站点条款，每天点一次风险不大，但你自己心里有数
