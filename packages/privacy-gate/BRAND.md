# ShyPie brand assets

The ShyPie mark identifies the ShyPie project and this Magpie middleware. It is
the complete pie holding a shield with a gold chevron.

## Assets

| File | Use |
|---|---|
| `assets/shypie-icon.svg` | Primary mark on the pale mint background |
| `assets/shypie-icon-dark.svg` | Mark for dark surfaces |
| `assets/shypie-icon-transparent.svg` | Transparent-background artwork |
| `assets/shypie-icon-mono.svg` | One-color line/mono mark, transparent |

The README uses the primary mark with a dark-mode `picture` fallback. The gold
chevron is the shield's only emblem; it contains no third-party vendor mark.

## Palette

| Token | Hex |

## Ownership

The ShyPie name and logo belong to the ShyPie project. The mark contains no
third-party vendor logo.

The source-of-truth vector package is maintained in
[`siml1169/ShyPie/assets/brand/shypie`](https://github.com/siml1169/ShyPie/tree/main/assets/brand/shypie).
The in-tree copies are provided so the README and package page render without an
external dependency.
