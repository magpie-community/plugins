# v0.2.1 · 历史搜索兼容修复

- 修复历史过滤删除旧 `reasoning` 后，仍重放原生 `web_search_call`，导致上游提示缺少关联推理条目的问题；同时避免重放该搜索调用的原资源服务器 ID。
- 开启历史过滤时，旧搜索转为带标记的普通助手文字，保留已记录的查询、动作、状态及来源，去除服务器 ID 与内部回合元数据。后续结论、引用和普通工具配对保留，不重跑搜索或补造结果。
- 转换逻辑编入独立请求入口，不依赖模型检测后台；按供应商开关执行，其他供应商直通。既有检测、暂停与探针放行逻辑保留。
- 精简 README，详细使用与迁移说明移至 `docs/USAGE.md`，补充维护目录说明。

## 更新

```sh
magpie plugin add @magpie-community/middleware-codex-history
```

社区审核合并并完成 dist 分发后，在 Magpie 插件页更新即可；现有市场安装项沿用原包名和 Options。需要独立 GitHub 版时也可下载 v0.2.1 ZIP 完整解压后添加本地目录。先私下备份原 Options 与 `~/.config/magpie-model-workbench/`，沿用供应商规则、检测目标、记录与暂停状态，只启用一个副本。不修改 Codex 的 `base_url`；只用过滤无需打开独立工作台。

本次修复适用于携带完整明文历史的普通对话与压缩总结。已加密的压缩历史、服务器引用及 `/responses/compact` 仍无法安全跨资源迁移，不属于本次支持范围。

验证覆盖离线回归、浏览器检查及隔离真实 Magpie + 模拟上游。GitHub 独立发版不会自动更新社区市场；社区发布状态以合并结果和 dist 索引为准。
