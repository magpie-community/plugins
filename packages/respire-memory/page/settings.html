respire-memory

吸即存，呼即取——让 AI Agent 在实践中积累经验，持续自进化。

首次使用：先安装 Respire 本体

此插件是 Magpie 的接入层，需要另行安装 Respire CLI（GitHub 安装说明）。它提供记忆库与本地 Runtime；只安装插件还不能读存记忆。

  1. 在自己的终端执行 npm install -g rsrs-cli，或从 CLI Releases 下载对应平台版本。
  2. 按 CLI Runtime 指南准备账号、模型，启动并解锁本地 HTTP Runtime。
  3. 执行 rsrs --client-only status --json 确认连接，再在下方配置 Runtime 地址及归档生成模型并保存。

插件不会代装 CLI、启动 Runtime 或管理账号；登录与解锁请在 Respire 中完成，不要在此页面输入密码或密钥。

仅连接 127.0.0.1 或 [::1]。请先通过 rsrs 准备好账号、模型和 Runtime。 填写后只召回该项目，并为新记录设置此项目。留空使用整个当前记忆库；工作目录不会自动成为项目边界。

开启采集后，用户与助手消息、工具参数和结果中的文件内容、命令输出均可能进入 Respire。日记仍按你的同步设置同步；这不会自动提炼为长期结论。

后台记忆整理 仅填变量名，不在此处输入密钥。变量应在 Magpie 启动环境中配置；插件不会读取客户端私有登录凭据。 留空使用用户目录的 .rsrs/magpie。状态与待处理证据加密保存在此处；密钥同目录保存，应按敏感资料保护整个目录。

完整读存流程需要配置生成服务。每轮自动归档默认开启；关闭或模型未配置时不能视为满足每轮必存。消息、工具结果与相关记忆会发送给此服务，并产生额外模型用量。宿主只在回复完成后通知，不能保证回复发出前已存；缺失历史或入队前丢失通知仍会漏记。只读开关在后续请求同步给 worker，不会撤销已接受的写入。

使用方式

完成上方 Respire CLI 安装与配置后，召回自动执行。“/nomem”或“#nomem”只跳过本条召回；已开启的采集与后台归档仍可运行。存储是否成功以模型收到的引擎回执为准。

连接失败时先按 Respire CLI 说明检查本体与 Runtime；原对话会继续。共享网关的其他调用者无法使用此插件读取或保存记忆。
