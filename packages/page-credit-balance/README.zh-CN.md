# 积分与 Token 余量

[English](README.md)

![插件图标](page/icon.png)

在 Magpie 里查看各供应商的积分余额、可用 Token 和历史消耗。[模型剩余额度](https://github.com/magpie-community/plugins/tree/main/packages/page-model-quota)侧重按模型估算额度。本插件允许手动匹配不同厂商的型号、对比高峰和低峰，并把余额折算成同一家供应商的积分。

## 安装

需要 Magpie 0.1.4402 或更新版本。用 `tar -xf` 解压 `.tgz`，然后把解压出的 `package` 目录交给 Magpie。若已下载社区仓库源码，可以直接传入 `packages/page-credit-balance` 目录。

```sh
magpie plugin add ./package
```

从 Magpie 侧栏打开 **积分与 Token 余量**。社区目录收录并发布后，也可使用 `magpie plugin add @magpie-community/page-credit-balance`。

## 使用方法

1. **折合积分**。先选基准供应商和精确型号。可用 **填入同名型号** 补齐同名项，遇到异名时展开供应商自行勾选。高峰和低峰各自使用来源和基准供应商在相同时段的费率。
2. **按型号看 Token**。选择目标型号，为各家勾上对应名称，再选择哪些供应商参与合计。每个账号的余额只算一次。选择多个型号时，按最近的 Token 用量比例估算，同时显示高峰和低峰结果。
3. **积分消耗**。可查滚动 24 小时、北京时间最近 7 日或 30 日。展开供应商可看各型号扣分、估算及无法归到具体型号的金额。页首是各家原始数值相加，需要统一单位时看折合积分。

## 怎么读这些数字

- 已核对金额来自请求的实际扣分和供应商计数。上次读取之后的新扣分可用请求记录补入。缺少账号归属的请求可能已在计数里，插件会避免重复相加，也会提示可能少计。
- 24 小时结合快照、当日官方计数和请求记录。只有自然日总账时，无法恢复昨天落入滚动窗口的精确扣分。余额新鲜度取决于 Magpie 最后一次读取供应商的时间。
- 供应商总额可以核对，型号拆分有时仍是估算。官方倍率需要用本供应商的扣分数据校准，缺少费率时会标记待查。签到、赠送、充值和周期重置会改变余额，下一次读取会按新余额重算。

## 数据和设置

插件服务仅监听本机回环地址，报表和偏好接口需要页面密钥。插件读取本地 Magpie 额度 API 和配置目录下的 `usage.jsonl`、`credits-daily.json`、`plugin-providers.json`、`providers.json`。偏好与短期计数快照保存在 `plugin-work`。插件没有遥测，也不直接请求厂商。端口 3498 被占用时，可在 Magpie 的插件选项中设置 `port`。

进入插件目录运行 `npm test` 检查计算和本地服务。项目采用 MIT 许可证，沿用了模型剩余额度的回环页面服务方式。
