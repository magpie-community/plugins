# 积分与 Token 余量

[English](README.md) · [维护仓库与标星](https://github.com/crbj621/plugins) · [下载最新版](https://github.com/crbj621/plugins/releases/latest)

![插件图标](page/icon.png)

不同供应商的积分购买力不同。同一个模型也可能在各家使用不同的名称和不同的时段费率。这个页面把已配置在 Magpie 里的供应商放在一起，帮你回答三个问题。

- **我一共还剩多少积分？** 选一家熟悉的供应商和一个型号作为基准，把参与计算的余额折为同一种积分，分别看高峰和低峰的合计。
- **指定型号还能跑多少 Token？** 为每家勾选与目标型号对应的一个或多个名称，再看各家和合计的峰谷余量。
- **最近的积分花到哪了？** 查供应商总消耗，再展开看模型明细与数据来源。

页面沿用社区 [模型剩余额度](https://github.com/magpie-community/plugins/tree/main/packages/page-model-quota) 的本地服务方式，增加了手动确认的跨供应商型号映射、统一积分折算和按账户核对的消耗统计。

## 安装

需要 Magpie 0.1.4402 或更新版本。到[发布页](https://github.com/crbj621/plugins/releases/latest)下载 `.tgz`。用 `tar -xf` 解压，在解压目录运行下面的命令。若已下载源码，可以传入 `packages/page-credit-balance` 目录。

```sh
magpie plugin add ./package
```

从 Magpie 侧栏打开 **积分与 Token 余量**。社区目录收录并发布后，也可使用 `magpie plugin add @magpie-community/page-credit-balance`。

## 使用方法

1. **折合积分**。先选基准供应商和精确型号。可用 **填入同名型号** 补齐同名项，遇到异名时展开供应商自行勾选。高峰和低峰各自使用来源和基准供应商在相同时段的费率。
2. **按型号看 Token**。选择目标型号，为各家勾上对应名称，再选择哪些供应商参与合计。每个账号的余额只算一次。选择多个型号时，按最近的 Token 用量比例估算，同时显示高峰和低峰结果。
3. **积分消耗**。可查滚动 24 小时、北京时间最近 7 日或 30 日。展开供应商可看各型号扣分、估算及无法归到具体型号的金额。页首是各家原始数值相加，需要统一单位时看折合积分。

### 峰谷折算示例

假设你选 WorkBuddy 为基准，另一家有 200 积分。两家选的是你确认过的同一型号，以下费率仅用于演示。

| 时段 | 另一家每百万 Token 扣分 | WorkBuddy 每百万 Token 扣分 | 另一家可用 Token | 折合 WorkBuddy 积分 |
| --- | ---: | ---: | ---: | ---: |
| 高峰 | 4 | 10 | 5,000 万 | 500 |
| 低峰 | 2 | 8 | 1 亿 | 800 |

先用来源余额除以来源费率，得到可用的百万 Token 数，再乘以基准供应商同一时段的费率。选了多个型号别名时，按这些型号近期的 Token 用量占比估算费率，同一个账户的余额只计一次。

## 怎么读这些数字

- 已核对金额来自请求的实际扣分和供应商计数。上次读取之后的新扣分可用请求记录补入。缺少账号归属的请求可能已在计数里，插件会避免重复相加，也会提示可能少计。
- 24 小时结合快照、当日官方计数和请求记录。只有自然日总账时，无法恢复昨天落入滚动窗口的精确扣分。余额新鲜度取决于 Magpie 最后一次读取供应商的时间。
- 供应商总额可以核对，型号拆分有时仍是估算。官方倍率需要用本供应商的扣分数据校准，缺少费率时会标记待查。签到、赠送、充值和周期重置会改变余额，下一次读取会按新余额重算。
- 看到「费率或余额待查」时，可展开该供应商检查型号映射和数据来源。有供应商账单可对照时，也可在「设置费率」按每百万 Token 的积分填写峰谷费率，清除手填值即可恢复自动计算。

## 维护与反馈

从 Magpie 插件详情的「主页」，或点击[维护仓库](https://github.com/crbj621/plugins)，可在 GitHub 查看发布记录并标星。反馈积分差异时，附上供应商、型号、统计窗口和页面显示的数据来源即可。

## 数据和设置

插件服务仅监听本机回环地址，报表和偏好接口需要页面密钥。插件读取本地 Magpie 额度 API 和配置目录下的 `usage.jsonl`、`credits-daily.json`、`plugin-providers.json`、`providers.json`。偏好与短期计数快照保存在 `plugin-work`。插件没有遥测，也不直接请求厂商。端口 3498 被占用时，可在 Magpie 的插件选项中设置 `port`。

进入插件目录运行 `npm test` 检查计算和本地服务。项目采用 MIT 许可证。
