# Changelog

## 0.1.0 — 2026-11-07

- Add a Magpie Agent row for Nowledge Mem / AI Now.
- Synchronize Default, AI Now and Background through a dedicated native Magpie provider instance.
- Preserve original assignments in a recovery journal; protect manual changes and recover interrupted operations.
- Include private state files, separate backend authentication, CLI diagnostics and emergency restore.
- Provide credential-free unit/HTTP tests, an opt-in actual-Magpie smoke test and a restricted Nowledge API contract check.

Compatibility verified with Magpie 0.1.3212 and Nowledge Mem 0.10.115. Real paid inference, other operating systems and subsequent Nowledge versions are outside the first release's validation.
