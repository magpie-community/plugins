iPhone 额度组件

扫一次码，手机就能自己装好组件。

—

在 iPhone 上

  1. 手机和电脑连在同一个 Tailscale 里（用自定义地址时，让 iPhone 能访问那个地址就行）。
  2. 用相机扫上面的二维码，打开配对页。
  3. 在下载列表里用 Scriptable 打开下载的脚本。
  4. 长按 iPhone 桌面，添加 Scriptable 小组件，选 UsageWidget。

小组件

这里选的是小组件的样子：数字是「剩余」还是「已用」，小号组件显示哪一张卡片。不用再去 Scriptable 里敲参数了。手机上那个参数还能临时改一次，改完只影响那一个组件。「跟着第一个有数的」= 今天网关报过数的那一张；网关今天没报这个账号，组件上就只有一个破折号。

设备管理

扫码的时候手机自己换到一枚只读的令牌，服务这边只留它的指纹。令牌是每台手机一枚，所以撤销哪一台就只停哪一台。撤销之后这一行还留在名单里（当作个记录），再点「删除」才把它从名单上划掉；一台自己走掉的手机（组件读到令牌作废、或手机页面按了「断开」）也会把自己的行带走。扫码这条路你一次也不用手抄令牌。
