What is sent

Recall sends the latest user turn to the configured Mem URL, even when saving conversations is off.

Saving conversations is off by default. When enabled, completed user and assistant turns are imported to that Mem, plus client tool results unless captureTools is off. Remote callers require separate opt-ins.
