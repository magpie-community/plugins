# Magpie Company Guard

Local company-name masking and reversible replies for Magpie, with session approvals and local receipts.

当前版本：**0.4.7**（macOS）。

面向 Magpie 的公司名称保护插件：在模型请求发送前替换识别到的公司名称，在回复返回本机时还原；提供“会话授权”“脱敏规则”和“脱敏回执”三个页面。

## 功能与边界

- 检查请求中的用户文字、历史、工具结果、工具参数和工具说明，支持 Responses、Chat Completions、Anthropic Messages、Gemini 协议。
- 根据企业名称规则、明确的名称字段、简称定义及用户配置识别名称，同一会话内使用稳定代号。
- 支持 Codex 单会话原名放行，可选指定名单或全部公司名称；其他会话、分叉和子任务不自动继承。
- 保留最近 25 份回执；名称对应明细仅在插件宿主内存中限时保留，最长 30 分钟。磁盘回执不保存原名、代号或消息全文。

这是规则识别工具，不能保证发现所有公司名称，也不能作为完整的数据防泄漏边界。图片、音频、文件二进制内容及绕过 Magpie 的连接不在检查范围内。宿主超时、回调缺失或请求被跳过时，不能视为已完成保护。

本版仅支持 macOS，安装包已声明此限制；Windows 和 Linux 不在本版支持范围内。会话授权依赖 Codex 的会话元数据，其他客户端默认执行名称脱敏。插件不修改源文件或业务数据库，Magpie 自带的其他隐私保护继续按原配置运行。

## 安装与首次运行

支持 macOS，需要 Magpie 0.1.3841 或更新版本。运行时使用 Magpie 自带的 Bun，无需另外安装 Node.js 或 npm。只启用一份本插件，避免两份安装同时处理请求。

在终端执行：

```sh
magpie plugin add @magpie-community/middleware-company-guard
```

如果标准 App 已安装，但终端找不到 `magpie` 命令，可使用：

```sh
/Applications/magpie.app/Contents/MacOS/magpie plugin add @magpie-community/middleware-company-guard
```

安装后打开 Magpie → 公司名称保护。首次加载时，插件自动生成三个随机密钥，保存在本机状态目录的 `keys.json` 中，文件权限为 `0600`，目录权限为 `0700`。插件会把缺失的密钥同步到自身的 Magpie 选项，使中间件、请求 Hook 和页面使用同一套凭据；不需要手动运行配置脚本。

已有有效密钥、会话授权、自定义端口和其他选项继续沿用。重启不会重新生成密钥。若已有文件权限不安全、密钥损坏或两处配置冲突，初始化会停止并保留原配置，请先排查重复安装或配置变动，不要通过删除密钥文件尝试恢复。

默认页面端口为 `3469`，已核对本次社区插件源码未使用此端口。它只监听 `127.0.0.1`；可通过插件选项 `receiptPort` 调整。升级时已有端口设置不变，原来显式配置的 `3478` 仍会继续使用；如果同时安装 AtomCode 等使用该端口的插件，应为本插件另设端口。

默认状态目录为 `~/.config/magpie/company-guard`；设置了绝对路径 `XDG_CONFIG_HOME` 时，使用该目录下的 `magpie/company-guard`。显式配置的 `stateDir` 优先。密钥、授权目录和含密钥的插件选项只留在本机，不要提交或发送给他人。

## 会话授权

1. 可在“会话授权 → 最近回执涉及的会话”中点击“申请取消脱敏”，也可在目标 Codex 会话单独发送“申请取消脱敏”“取消脱敏”或“原名放行”。加粗、行内代码等常见格式也可识别。
2. 打开“公司名称保护 → 会话授权”，核对会话和工作目录，选择范围并确认。申请本身不启用授权，待确认项保留 24 小时。
3. 名单模式最多 32 个完整名称，别名须单独列入；全部名称模式也覆盖该会话后续请求携带的历史和工具文字。
4. 待确认申请可在右侧查看。点击“设置放行范围”打开确认弹窗；取消或关闭弹窗保留申请，“拒绝申请”会关闭本次申请，不改变现有授权。被拒绝后，在七天内仍可沿用原来已核验的目录重新提出申请，但必须再次确认范围。
5. 在左侧“已启用授权”表格点击“恢复脱敏”并确认，后续请求恢复默认处理。已经发送的原文不能撤回。

授权只在本机保存，持续到用户主动撤销。普通回答结束、追问或中断后继续，不会自动撤销授权。页面批准、撤销使用独立凭据，回执读取凭据不能批准授权。

## Codex 申请轮收尾

可将以下规则加入你自己的 Codex 指导文件；安装本插件不会自动修改它。

> 独立原名放行申请：按本会话编号和工作目录只读核对一次状态，如实最终答复并收尾，不等页面审批；原业务保留，续办按用户指令。

## 脱敏规则

“脱敏规则”下设“内置识别”和“自定义规则”两个子页面，默认打开自定义规则。内置识别说明公司全称、明确名称字段、材料中的简称定义及识别边界；自定义规则可新增、编辑或移除名称，为同一主体配置多个简称与别名。名称按文字匹配，不执行正则表达式；名称与别名合计最多512个。不同写法分别生成代号并按原写法还原，不提供自动主体归并。

切换子页面或主页面时，有未保存修改会先提示。自定义区域底部显示规则版本摘要，会话授权页另有授权变更记录，两者最多展示100条摘要，与最近25个请求的回执保留窗口分别计算。历史摘要不含原名、密钥或会话正文；旧摘要缺失不代表从未变更。并发修改会先核对版本，避免覆盖其他窗口的规则。

## 回执

在“脱敏回执”页面先选智能体，再选会话任务，查看替换数量和限时明细。任务列表随智能体选择变化，筛选范围仍是所有智能体合计保留的最近 25 个请求；某个智能体没有匹配回执时会显示空结果。处理结果按“已完成、待完成确认、需关注”三组汇总，具体原因保留在明细中。

页面可见时默认每 10 秒刷新，展开明细时暂停；关闭自动刷新后，页面保留最近一次结果。刚发起的请求在回复结束前可能暂时等待确认，这与处理失败分别记录。

同步检查和回复处理的确认会随回执保存，日志轮转不会抹去已保存的确认。同步检查、回复处理及正常流式结束事件均已确认时，可以据此确认完成；明细会区分流式确认与宿主确认。缺少必要检查、宿主明确报告失败或回复仍有本次代号残留时，不会标为完成。未命中不代表没有敏感名称。

桌面版默认读取 macOS 的 `~/Library/Logs/magpie/app.log` 来核对处理确认。使用 `magpie web` 或自行重定向日志时，可在插件选项 `appLog` 中指定实际日志文件的绝对路径。保存的阶段确认和当前日志共同用于核对。必要依据仍不齐全时保留未确认状态，不会仅因等待时间较长而标为成功。读取时会报告回执损坏或截断问题，并保留可恢复的有效阶段记录，不能把缺失记录当作已完成。

可从源码目录读取本机计数报告：

```sh
node receipt-report.mjs --json
```

本仓库不包含用户配置、授权名单、业务材料或本机验收记录。

## 0.4.7 更新

脱敏回执按每条请求展示；会话授权页另外汇总所有日期合计保留的最近25条回执所涉及的会话。某个会话的最后一条回执移出窗口后，它会从近期会话列表消失，已启用授权仍在左侧表格中管理。近期会话以标题为主，来源标签、回执数及授权信息在下方分组显示。

全部名称授权校验通过后，正常成功的请求不再新增普通回执；部分名称放行、授权校验异常和处理失败仍会记录。这里的“已放行”表示当前授权设置，历史回执明细保留当时的实际处理结果。后台任务单独识别，不继承主会话授权；缺少可核验工作目录的请求不能从列表申请放行。

## 授权容量与记录清理

授权表最多100条登记，普通已撤销记录在后续授权操作中清理，不再永久占位。有效授权不会因容量不足被自动删除；仍有旧独立授权的会话，保留必要的撤销标记，防止旧授权重新生效。授权变更摘要另行保留，不依赖当前授权表保存历史。

页面校验、授权规划和请求处理共用100条上限。授权表序列化长度最多3×1024×1024个字符，授权接口正文最多4 MiB；每份指定名单最多32个名称。待确认申请另按64条、24小时计算。归档Codex会话不会自动撤权，需要在插件中主动恢复脱敏后才能释放相应名额。

回归检查覆盖连续授权、撤销106个不同会话后再批准一个会话，已有64条撤销记录的恢复、满100条有效授权的请求处理、容量不足时保留有效授权、旧版撤销标记保护及大小限制。本次未进行30、50、100条记录的延迟压测，不提供未经测量的延迟承诺。

## 开发与测试

```sh
npm ci
npm test
npm run build
```

开发和测试需要 Node.js 20 或更新版本。测试使用独立的临时配置和虚构名称，覆盖四种协议的往返处理、流式分段还原、工具参数、会话授权与撤销，以及首次初始化和密钥权限。同一套测试还验证已构建中间件与 Hook 的协作、工具结构中的默认值和示例脱敏、规则校验及审计摘要、损坏回执恢复、日志轮转和回执淘汰后的快照核对，并检查失败通知和代号残留不会被提升为成功。构建检查要求已提交的中间件与源码一致。

`dist/` 已提交，可直接从 Git 安装，无需安装时构建。运行时使用 Magpie 自带的 Bun，无额外 npm 运行时依赖；esbuild 仅用于开发构建。社区版本由本仓库的分发流程提供；上述社区安装命令在 PR 合并并完成分发后可用。合并前，可从仓库根目录运行 `magpie plugin add ./packages/company-guard` 进行本地验证。

插件接口见 [Magpie 官方文档](https://usemagpie.ai/docs/plugins)。提交问题时，请使用不含真实名称、凭据和会话内容的必要诊断信息。
