    新钥匙

    一键签发网关 Key，可直接接到任意 Agent，无需跑命令。

    http://127.0.0.1:3425/v1
    默认 Auto；也可指定已有路由组或单模型。
    创建后 Magpie 会签发一把网关 Key；明文保存在本机，之后仍可通过「查看」复制。
    正在签发…
    1. 向 Magpie 签发网关 Key
    2. 写入模型限制（如有）
    3. 放入本地钥匙柜
    4. 完成，展示 Secret
    ✓ 钥匙已放入，请立即复制网关 Key

    关闭后默认只显示掩码。可在钥匙详情里「查看」或「重置」。把 Base URL + Key 填进任意 Agent 即可接入。
