What is sent

Recall sends the latest user turn to the configured service URL above, even when capture is off.

Capture is off by default. When enabled, complete user and assistant turns, client tool calls and results, including files and command output read by the Agent, are sent to that same service. Remote recall and capture require separate opt-ins.

Deployment

Run PowerContext independently, then connect Magpie.

  1. 1

    Deploy the service

    Follow the official quickstart for the current installation and startup commands. This plugin connects to your service; it does not install or start it.

  2. 2

    Prepare models and a Scope

    Configure Generation, Embedding and the Memory schedule on the Server. Use an explicit Scope, a session/workspace binding or the service’s default Scope.

  3. 3

    Connect in Magpie

    Enter the service URL, optional Scope ID and service key in Connection settings. Leave the key empty if authentication is disabled. Enable conversation capture when ready.
