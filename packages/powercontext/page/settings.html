Deployment

Run PowerContext independently, then connect Magpie.

  1. 1

    Deploy the service

    Follow the official quickstart for the current installation and startup commands. This plugin connects to your service; it does not install or start it.

  2. 2

    Prepare models and a Scope

    Configure Generation, Embedding and the Memory schedule on the Server. Create a Scope and keep its scope_id.

  3. 3

    Connect in Magpie

    Enter the service URL, Scope and service key in Connection settings. Leave the key empty if authentication is disabled. Enable conversation capture when ready.
