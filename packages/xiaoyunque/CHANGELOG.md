# 更新记录

## 0.1.2

- 新增 `video_process` 工具，支持视频超分（`super_resolution`）与视频擦字幕（`erase_subtitle`），复用 `result` 查询与下载。
- 首次提交任务时按账号默认关闭 AIGC 水印（`update_user_setting`，每凭据仅同步一次，不影响提交主流程）。
- 对齐官方 CLI `v1.0.53` 的 `get_thread` 业务错误分支解析：响应返回 `ret !== "0"` 但附带目标 `run` 时，继续提取终态与脱敏后的失败原因。
- 本地参考素材改为内部 `Symbol` 标记直传二进制字节，消除 Base64 编码/解码内存放大，且防止 HTTP 外部伪造本地路径。
- 原生图片轮询新增默认 5 分钟总超时保护（超时返回 `409` 保留原任务）；`loader` 每次请求读取最新凭据；任务历史目录自动裁剪至最多 200 条；登录 `cli_version` 对齐至 `1.0.57`。

## 0.1.1

- 修复 `/v1/videos` multipart 请求中 `image` 被错误归入参考图而非首帧的问题。
- 图片组合 `size` 支持 `adaptive` 比例与小写分辨率（如 `adaptive@2K`、`16:9@2k`），修正参数覆盖提示误报。
- 严格校验视频比例枚举，拒绝空白字符串隐式转为 `adaptive`；移除不可达死代码。
- 修复 `accountAuth` 按任务恢复原账号时在异常条目或同 UID 多槽位下的边界错误。
- 修复 `generate` 工具在缺少 `context.directory` 时读取本地绝对路径报错。

## 0.1.0 · 首个公开版本

- 在 Magpie 供应商页通过网页登录或 Access Key 使用小云雀，凭据由 Magpie 保存。
- 按当前账号读取图片／视频模型、参数、创作模式和积分，接入原生媒体入口。
- 提供 `models`、`generate`、`result` 三个工具，支持参考素材、首尾帧、视频编辑／延长请求，以及用户确认后的 Draft 升级。
- 普通调用沿用 Magpie 的尺寸、质量、时长和首帧参数，高级参数按实时模型目录校验。
- 支持原任务恢复、有限等待和本地下载；失败不自动重提，不覆盖已有文件。
- 提供 Magpie、OpenCode 1.x／2.x 入口，无运行时依赖；完整媒体体验以 Magpie 为准。
