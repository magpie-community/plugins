# Yuri artwork

The Agent icon (`agent.icon`) and plugin-card icon (`package.json`'s
`magpie.icon`) embed the same original PNG, without redrawing or recoloring:

- Source: `assets/brand/yuri/yuri-b-icon-light-32.png` in
  [yee94/yuri](https://github.com/yee94/yuri).
- Size: 32 × 32 pixels, 1,799 bytes.
- SHA-256: `aacc7c4365bb7f90723634aa70351c150160ee028818e35314fbf9b04baa9dac`.
- The image is a data URI so neither surface needs a network connection.
- A single light-background app icon is used in both Magpie themes; the
  Agent descriptor does not offer separate light/dark icon fields.
