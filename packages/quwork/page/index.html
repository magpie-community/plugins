QuWork 接入

登录时选择「官网浏览器登录」，插件会打开专用浏览器窗口，在 QuWork Web App 完成登录并自动读取官方会话。

官网登录

在 Web App 右上角点「注册 / 登录」，选择短信验证码或微信登录；也可以直接使用 Magpie 的官网浏览器登录。

在 Magpie 内打开 Web App

如果页面没有跳转，请复制 https://qurwork-llm.rrzu.com/ 到系统浏览器打开。

积分余额

官网登录成功后，Magpie 会读取账号 token；如果 QuWork 同时返回模型凭据，额度页会显示积分并可直接调用模型。

每日签到

自动签到：在 设置 → 用量 → 插件 → QuWork 打开「每日签到」（默认关闭）。

手动签到：在 供应商 → QuWork → 账号用量卡片 点「立即签到」。

签到需要 Web App 登录保存的官方会话；旧的官网 token 账号需要重新用「官网浏览器登录」建立会话。

只填写 sk- 模型密钥的账号不能签到。

如果上游返回「无权进行此操作，权限不足」，插件会标记为不可签到，不会自动重试。

无法保证账号不被限制；建议先确认 QuWork 官方条款，并保持单账号、低频、失败不自动重试。

接入 Magpie

如果官网登录没有返回模型凭据，获得 QuWork 授权的模型密钥后，前往 供应商 → QuWork → 登录 填写 sk- 密钥。

如果供应商列表里还没有 QuWork，在 插件 → 已安装 启用此插件。必要时重启 Magpie。
