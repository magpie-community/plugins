QuWork 接入

请在 QuWork 官网登录账号。Magpie 的模型调用需要 QuWork 授权用于第三方接入的模型密钥。

官网登录

在官网右上角点「注册 / 登录」，选择短信验证码或微信登录。

打开 QuWork 官网

官网地址 https://quwork.cn/

积分余额

持有有效旧版积分凭据的账号可在 Magpie 额度（Quota）→ QuWork 查看余额。通过模型密钥接入的账号请在 QuWork 官方入口查看积分。

接入 Magpie

获得 QuWork 授权的模型密钥后，前往 供应商 → QuWork → 登录 填写密钥。自动关联官网账号需要 QuWork 提供面向 Magpie 的授权接口。

如果供应商列表里还没有 QuWork，在 插件 → 已安装 启用此插件。必要时重启 Magpie。
