# QuWork for Magpie

实验性社区供应商 `quwork`，支持在本机浏览器手动完成手机号、人机验证和短信验证码验证。登录无需安装 QuWork 桌面客户端。插件内置 10 个模型条目，实际可用模型由 QuWork 和账号权益决定。

## 账号风险

浏览器接入使用 QuWork 非公开客户端接口。尚未查到 QuWork 允许第三方客户端消耗个人账号积分的授权。官方协议第 2.3.2 条规定未明示授权的权利需另获书面许可，第 8.1 条限制逆向工程，第 8.2 条允许对违规行为暂停或终止服务。个人账号也存在风险，重要账号建议使用官方入口。阅读 [Clawork 软件许可及服务协议](https://llm.rrzu.com/claw-agreement)。

## 安装与使用

在 Magpie 的「插件 → 添加插件」选择本地插件目录，或在社区仓库根目录运行 `magpie plugin add ./packages/quwork`。启用后，前往「供应商 → QuWork → 登录」并选择「浏览器登录 QuWork（实验性）」。本机页面提示短信验证通过后，回到 Magpie 确认登录状态。

已从 QuWork 获得第三方接入授权的用户可在登录菜单单独填写模型密钥。模型密钥的权限限于模型调用，查询积分需要账号授权。

在 Magpie 的「额度（Quota）」页查看 QuWork 账号的积分总余额。上游提供限时或永久积分字段时会一并显示。查询失败会显示原因，余额为零只在上游确实返回零时显示。命令行也可查询：

```powershell
magpie quota quwork
```

## 凭据与查询

- 登录页仅在 `127.0.0.1` 提供一次性地址，校验请求来源。发送短信有冷却时间，登录会话有尝试次数与时限。
- 浏览器完成验证后，Magpie 保存模型密钥与查询积分用的账号凭据。请只在自己的账号上使用，并保管好 Magpie 的账号配置。
- 模型密钥发送到指定的 QuWork 模型网关。积分来自 QuWork，短时间内的重复查询使用按凭据隔离的内存结果。
- 现有的桌面登录态导入方式已移除。此前导入的账号可使用曾保存的模型密钥，查询积分需要独立登录。

## 开发验证

在插件目录运行 `node --test index.test.mjs`。模拟测试覆盖本机登录与额度显示，使用测试数据。社区仓库从根目录运行 `bun scripts/check.mjs quwork`。社区代码采用 MIT 许可。
