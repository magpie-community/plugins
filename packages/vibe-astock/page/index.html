Vibe AStock × magpie

让 Vibe AStock 的对话、六阶段研究和回测，都用这台机器上的 magpie 网关出模型。

1确认网关在跑

magpie 默认监听 127.0.0.1:3425，OpenAI 兼容前缀是 /v1。改过 MAGPIE_ADDR 就用你改后的地址。

http://127.0.0.1:3425/v1

2把 Vibe AStock 接上

在 Vibe AStock 仓库目录里跑一次（它会写 .local/providers/magpie.json，并把这个网关的每个模型放进「接入 AI」的下拉）：

npx vibe-astock-magpie install

不想装命令行工具也行：Vibe AStock 页面「接入 AI」→ 选「其它 OpenAI 兼容端点」，把下面三项填进去。

3在 Vibe AStock 里选一个模型

装好插件后，「接入 AI → API 接入」的模型下拉里会直接列出这个网关的每个模型（前缀 Magpie ·）。挑一个就行：

Magpie · GLM-5.3-Flash —— auto/glm-5.3-flash

Base URL（http://127.0.0.1:3425/v1）、Model（该模型的 id）、API Key（magpie） 会跟着自动带出，不用手抄。在 magpie 里加了新模型后，跑一次 npx vibe-astock-magpie models 再刷新页面。

4点「测试并保存」

Vibe AStock 会先真发一轮对话，成功后才保存。之后对话、六阶段研究、多空辩论、回测都走这一个来源。

已知边界：服务端 JSON Schema 约束在 magpie 上不生效，结构化输出走提示词（产品自己的校验照旧把关）； 图片输入不支持，所以「从截图或表格识别」用不了，文字资料不受影响。
