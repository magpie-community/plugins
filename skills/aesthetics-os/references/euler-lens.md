# 欧拉透镜（euler_lens）：把 e^(iθ) 的数学结构迁移为美学工具

> 不是「欧拉魔法让图变美」。欧拉公式不会自动产出美。它给出几条**可严格验证**的数学结构，
> 让我们用原则性的方式分析色彩和谐、纹理自然度与构图重力，并据此指导生成。
> 裁决美丑仍归 critique（真实视觉）；本透镜只描述结构，不替代判断。

## 内涵：欧拉公式说了什么

`e^(iθ) = cosθ + i·sinθ`。它把**直线增长**（指数）与**圆周旋转**（三角）统一为一个运算：
乘 `e^(iθ)` 就是在复平面旋转 θ。由此生出三条可迁移结构：

| 数学结构 | 图像美学迁移 | 可验证性 |
|---|---|---|
| 色相环 = 单位圆，色相 = 相位 θ | 色彩和谐 = 相位关系（互补=+π，三角=±2π/3，邻近=小Δθ） | 精确数学，已验证 |
| 傅里叶 = 复指数分解（FFT 基石） | 幅度谱 P(f)∝1/f^α，自然图像 α≈1.8-2.3 | 可测，但有构图混淆 |
| 傅里叶相位 θ（结构所在） | 相位一致性 PC=结构特征；Gabor 方向熵=材质自然度 | 已验证（边缘16.9×；塑料vs自然可分） |
| 对数螺线 e^((a+ib)θ) = 生长×旋转 | 黄金螺线构图视觉重力（每转90°半径×φ≈1.618） | 已实现，参照非裁决（含跨文化caveat） |
| 恒等式 e^(iπ)+1=0（五常数统一） | 系统一致/克制：多元素服从一个深层结构 | 审美反射，非数值 |

## ① 色相相位和谐（最干净、最可直接指导生成）

色相本来就是角度（HSV 的 H 是 0-360°），所以色相环**就是**复平面单位圆，每个色相是 `e^(iθ)`。

- **resultant R = |Σw·e^(iθ)| / Σw**（圆统计，权重=饱和度×明度）：
  - R→1：色相高度集中（单色/邻近）；R→0：平衡展开（互补/三角）。
  - 饱和度极低（水墨/灰阶）→ 色相无定义，判 `achromatic`，和谐由墨色浓淡而非色相决定。
- **和谐调色板生成**：`harmony_palette(base, scheme)` 用相位旋转 `e^(iΔθ)` 从基色推出和谐色组。
  这是**指导生成 prompt 的原则性工具**——先按数学设计和谐，再让生成去实现。

```bash
python scripts/euler_lens.py palette 210 --scheme triadic      # 蓝→210/330/90
python scripts/euler_lens.py palette 30 --scheme split         # 琥珀→30/180/240
python scripts/euler_lens.py hue 成品.png                      # 实测 R/主色相/和谐类型
python scripts/euler_lens.py circle 成品.png --out 色相圆.png   # 可视化相位向量
```

**实证**：用分裂互补（琥珀30/青180/蓝240）指导生成暮色山水，实测主色相 [35°,195°]、
R=0.354（互补平衡）、谱 α=2.365（自然区间），目检电影感高级无硬伤。设计的暖冷相位对立被生成实现且可测。
**诚实边界**：生成是**近似**调色板（渐变中蓝并入青簇），不是像素级服从 hex；但结构和谐达成且可测。

## ② 傅里叶自然度谱（有用，但有明确混淆）

FFT 把图像分解为复指数 `e^(iωx)`（欧拉公式的二维化）。径向功率谱斜率 α 度量全局纹理平衡：

- 自然照片/绘画 α≈1.8-2.3；平滑渐变塑料感 α 偏大（高频缺失，如 aurora α=3.28）；
  密集纹理 α 偏小（如 qianli 皴笔 α=1.74）。

```bash
python scripts/euler_lens.py spectrum 成品.png
```

**⚠️ 诚实边界（不可单独裁决）**：全局径向谱被**构图混淆**——大片留白会主导谱。
寒江独钓留白 89%，船占画面极小，谱斜率反映的是纸白而非笔触（r1→r4 α 反而 2.50→2.61）。
所以 α 是「全局纹理平衡」信号，`flat_confounded` 标志会在近平坦像素 >60% 时警示，
**必须与 measure.py 的 flat_area/edge_density 合看**，不可当普适自然度分。

## ②b 傅里叶相位——被忽略的另一半（结构所在）

`e^(iθ)` 有幅度 |F| 和相位 θ 两个分量。上面的 spectrum 只用了**幅度**；而图像的结构信息
主要藏在**相位**里。已用实验证明：两张图互换傅里叶相位，重构图的构图跟着**相位供体**走
（相关 0.626 vs 幅度供体 0.218）；只留相位结构仍在，只留幅度结构塌缩。

**相位一致性 PC**（`pc`）：各尺度滤波响应是 phasor `A_s·e^(iφ_s)`，特征处相位对齐→相长，
`PC = |Σ_s A_s·e^(iφ_s)|` 减噪声门限。这和色相 R 是**同一个圆统计量**——欧拉相位贯穿色彩与结构。
- 光照不变的结构特征图。峰度高=少数强特征（极简孤主体）；峰度低=特征弥散（密集纹理）。
- 实证：寒江 PC 集中在孤舟、留白≈0（峰度22.4）；千里江山 PC 沿皴笔弥散（峰度5.0）。
- ⚠️ 是结构描述器，不单调追踪塑料→自然，须与 gabor 合看。

**Gabor 方向谱**（`gabor`）：Gabor=`e^(iωx)·高斯窗`（视觉皮层 V1 细胞模型），各方向能量→方向分布。
- **方向熵低 + 各向异性高 = 平滑方向性渐变（塑料感）；方向熵高 = 笔意多样（自然材质）。**
- 实证：aurora 平滑渐变 方向熵0.696/各向异性0.574→塑料感；qianli 皴笔 方向熵0.995/各向异性0.16→自然。
- 这是「材质真实」红线第一份频域硬证据。

```bash
python scripts/euler_lens.py pc 成品.png --render pc热图.png
python scripts/euler_lens.py gabor 成品.png
```

## ③ 黄金螺线构图重力（已实现，参照非裁决）

`e^((a+ib)θ)` 实部生长、虚部旋转 → 对数螺线。黄金螺线 `b=ln(φ)/(π/2)≈0.3063`，每转 90° 半径 ×φ。
`spiral` 用 PC 结构图算视觉权重重心，对照 φ 网格黄金点（0.382/0.618）：

- 偏心主体常贴黄金点：bada 孤鸟重心距黄金点 0.022、寒江孤舟 0.020。
- 居中/对称构图重心距中心近：千里江山 0.025——判「居中（合法，非硬伤）」，不贬低。
- `render_spiral` 叠加螺线（取最贴合重心旋向）+ φ 网格 + 重心标记。

```bash
python scripts/euler_lens.py spiral 成品.png --render 螺线叠加.png
```

**⚠️ 跨文化 caveat（已写进工具）**：黄金螺线是西方构图启发式，中国水墨计白当黑/留白未必遵循，
低对齐≠差。它是构图几何参照，裁决仍归 critique 对照命题。

## 实现与验证陷阱

- **相位一致性用绝对相干能量，不用比值**：`|Σresp|/Σ|resp|`（phasor resultant）在低幅度区病态——平坦区微小响应也算高 PC，再除 ΣW 归一化会让平坦区 0/0 复活。用 `|Σ_s A_s·e^(iφ_s)|` 减噪声门限（最细尺度幅度中位数×k），平坦→0、边缘→大。
- **频域特征先过合成正确性门再信**：实现 PC/方向谱后先用合成图验证（锐边 PC 须远高于平坦 ≥3×；已知方向光栅各向异性须高）。过不了门是公式错不是阈值问题，别调阈值掩盖。
- **进模块前在真实图上验证判别力**：合成门只证公式对，不证美学信号有用。须在真实成品上确认能分开目标类别（如塑料渐变 vs 自然笔意）再写进模块；分不开就降级为描述器或弃用，别先吹。
- **全局频域指标被构图混淆**：径向谱 α 与 PC 都被大留白主导，是结构描述器，不单调追踪塑料→自然；干净的材质判别是 Gabor 方向熵。全局指标须与 measure 的 flat_area/edge_density 合看。

## 在闭环中的位置

```
设计和谐调色板（euler_lens palette，相位旋转）
   → 写进生成 prompt → 生成
   → measure 测结构 + euler_lens hue/spectrum/pc/gabor 测色彩和谐、纹理与结构
   → critique 真实视觉判质量（色彩和谐引用 R/相位，材质真实引用 gabor 方向熵/pc）
   → revise 则改 → pass 才放行
```

欧拉透镜抬高的是**下限的原则性**：色彩和谐有数学依据而非凭感觉，纹理自然度有频域信号。
它不创造美，但让「和谐」与「自然」从玄学变成可设计、可测量、可迭代的东西。
