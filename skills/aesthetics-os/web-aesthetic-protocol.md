# 网页审美协议

用于视觉重要的网站、落地页、作品集、网页应用、产品界面与重设计。

## 不可跳过的顺序

按顺序执行：

1. 确认审美任务，并选择一个主要执行 Skill。
2. 建立视觉证据和任务专属品味简报。
3. 先制作一个代表性方向，再扩展完整界面。
4. 使用执行 Skill 实现。
5. 渲染并完成技术验收。
6. 对照简报与参考资料，单独完成审美验收。
7. 修复影响最大的偏差，再次检查。

不要因为实现很快或时间紧张就跳过前置门槛。

## 门槛一：品味校准

完整实现前，建立任务专属品味简报：

- **目的：** 页面必须帮助受众理解、感受或完成什么。
- **受众与情境：** 谁会在什么环境下看到它，信任预期是什么。
- **参考证据：** 一至三个用户提供、查找、生成或曾经确认的视觉参考。
- **喜欢的机制：** 明确指出构图、字体、图像、材质、节奏或动效。
- **拒绝的机制：** 明确记录要避免的模式，包括此前反馈。
- **审美命题：** 一句产品专属审美方向。
- **标志性动作：** 一个足以承载系统的独特视觉行为。
- **非目标：** 至少两个必须抵抗的方向。

“高级、现代、干净、人工智能、操作系统、电影感、东方感”等词只是待解决的问题，不是视觉证据。不得仅凭产品名称推导完整视觉系统。

用户提供参考时，必须先检查参考。没有参考且品味是主要成功标准时，完整构建前应采用一种方式建立证据：

- 生成两至三个真正不同的参考画面或情绪板方向；
- 构建一个代表性首屏或关键界面并检查；
- 选择一至三个精确先例，说明要借鉴哪些可见机制。

视觉证据必须可检查，例如图片、截图、渲染画面或可访问的视觉先例。纯文字情绪板、形容词列表、色板、设计令牌或设计说明不能满足该门槛。

即使用户要求自行判断，也要用视觉证据支撑方向，并进行独立复核。授权判断不等于允许依赖未经检查的模型默认风格。

## 门槛二：方向检查点

扩展完整界面前，确认代表性方向：

- 首屏能看懂产品、服务、地点、人物或工作流程。
- 可识别性、材质、地点、产品或氛围重要时，使用真实或生成的有效视觉资产。
- 字体系统经过明确选择，而非沿用未经判断的平台默认字体组。
- 先用构图建立层级，再使用效果。
- 只有一个标志性动作，不混用互相竞争的视觉隐喻。
- 方向属于这个具体主题，不能轻易替换文字后复用于任何产品。

用户偏好仍有实质不确定性时，展示检查点并获得方向反馈。用户要求自主执行时，在规则允许且资源可用的情况下使用独立审阅者；否则进行隔离式二次审阅，只查看简报、参考与新渲染，不沿用制作过程中的自我评价。

方向未通过检查前，不要投入完整实现预算。

## 门槛三：执行纪律

只选择一个主要视觉执行 Skill，并完整阅读其 `SKILL.md`，不得只读开头或节选。按该 Skill 自己的参考资料路由执行。

不要叠加多个品味 Skill 后平均风格。推荐职责分工：

- 审美操作系统负责命题、证据、一致性与最终审美门槛。
- 一个执行 Skill 负责设计和实现。
- 一个渲染验证流程负责浏览器检查。
- 只在需要时加入资产、字体、动效或产品逻辑等窄领域专家。

实现过程中持续对照品味简报。每个主要视觉选择都应能说明它服务于哪条参考证据或审美命题。

不要因为主题带有“人工智能、系统、设计、审美”等词，就自动使用网格、巨型字体、细线、玻璃卡片、渐变、深色科技风、超大汉字、抽象画布或灰调编辑风。只有证据和简报支持时才使用。

当用户需要情绪、材质、空间或产品专属证据时，不要用层叠样式特效或程序化画布装饰代替有意义的图像。

## 常见借口与纠正

| 借口 | 必须采取的行动 |
|---|---|
| “前端构建 Skill 已经负责设计。” | 仍由审美操作系统独立负责证据与品味门槛。 |
| “执行 Skill 太长，读第一部分就够了。” | 使用前完整阅读其 `SKILL.md`。 |
| “页面响应式正常且没有报错，所以设计通过。” | 只记录技术通过，另做审美验收。 |
| “这是我制作的，所以我能批准自己的品味。” | 对品味敏感或自主执行的工作进行独立或隔离式复核。 |
| “用户拒绝了两个方向，再换一个流行标签。” | 停止整页重写，回到可检查的视觉证据重新校准。 |

若出现这些念头，回到最早未满足的门槛，不要把跳过步骤解释为高效版本。

## 门槛四：技术验收与审美验收分离

渲染实际输出，检查桌面端、移动端以及重要状态与交互。

单独完成**技术验收**：

- 页面身份和有意义内容正常渲染。
- 没有运行错误、框架报错层、裁切、重叠或横向溢出。
- 控件、导航、动效与响应式状态可用。
- 资源正常加载且质量合适。
- 无障碍与减少动效模式仍可使用。

单独完成**审美验收**：

- 将渲染结果逐项对照品味简报和视觉参考。
- 检查首屏信号、层级、字体、构图、图像、材质、节奏、密度、动效、具体性与情绪。
- 记录偏差：`参考或命题 → 渲染证据 → 偏差 → 修复或有意偏离`。
- 指出最强决定和影响最大的一个弱点。

技术验收通过绝不等于审美验收通过。

## 独立复核

品牌、作品集、传播活动、产品发布或其他品味敏感的工作，在规则允许且审阅者可用时使用新的独立审阅者。只提供：

- 用户简报与约束；
- 品味简报；
- 视觉参考；
- 新生成的截图或成品。

不要提供制作方结论、目标评分、怀疑的问题或实现叙述。要求审阅者给出可见证据、最严重偏差，以及 `通过`、`暂定` 或 `修改` 的门槛结论。

没有独立审阅者时，用隔离式二次审阅代替：先隐藏制作过程结论，再仅凭上述材料重新判断。用户直接反馈始终高于模型共识；将拒绝转化为正向与负向约束，不争辩成品已经完成。

## 被拒后的恢复

一个方向被拒后，识别失败的形式机制，并提高概念距离，不要只给同一构图换皮。

两个方向被拒后，停止整页重写。使用参考资料、小型方向板或一个高杠杆品味选择重新校准。用户仍授权自主判断时，选择新的证据化方向，并在扩展前通过独立或隔离式检查点。

不要在没有新视觉证据时循环尝试“科技海报、编辑极简、现代东方”等流行标签。

## 完成门槛

分别报告：

- **技术状态：** `通过` 或 `失败`，附渲染证据。
- **审美状态：** `通过`、`暂定` 或 `修改`，附参考证据和影响最大的原因。

只有实际渲染成品通过审美门槛后，才能声称“好看、精致、高级、最终完成或审美完整”。高度主观的方向若尚未经过用户确认，应说明模型审美结论仍为暂定。
